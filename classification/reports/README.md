# 분류 실험 보고서

새 실험의 판단·작은 비교표는 이 폴더에, 실행 원자료는 각 보고서의 artifact-root에 둔다. 기존 결과는 [아카이브](../../archive/classification_v1/reports/README.md)에 보존한다.

| 날짜 | 보고서 | 상태 |
|---|---|---|
| 2026-10-15 | [7종 통합 비교](2026-10-15-seven-model-comparison/README.md) | 로컬 6종 + Jev, 14개 분할 평가 대조 완료 |
| 2026-10-15 | [새 학습 구현의 로컬 6종 상세](2026-10-15-learning-model-comparison/README.md) | 학습·저장·평가·CPU 속도 측정 완료 |
| 2026-10-15 | [Jev API 상세](2026-10-15-jev-evaluation/README.md) | 실제 API 268회 완료·예측 재검증 |

이번 탐색의 validation 최고는 RoBERTa base다. 작은 단일 합성 분할의 결과이며 test는 이미 열람한 개발 자료다. 최종 서비스 모델 선정은 보류한다. 과거 아카이브와 이번 실행은 학습 조건이 다르므로 새 실행의 결과를 과거 보고서에 덮어쓰지 않는다.

보고서에는 목적 → 실행 조건 → 결과 → 라벨별 지표·오분류 → 해석·결정 → 원자료 접근 방법을 기록한다. 실제 실행, 과거 기록, 가설을 구분하고 이미 열람한 합성 개발 test의 한계를 명시한다. 실행별 예측·가중치·전체 trial은 Git 보고서에 중복 수록하지 않는다.
