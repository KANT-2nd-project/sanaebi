# 사용자용 표현·서비스 범위 v5 결과

사용자가 연봉 질문의 내부 입력 중심 서두, 도움 범위 응답의 지침 선언, 일반 기술 질문의 부적절한 자료 부족 안내를 지적했다. v3는 보존하고 v4 중간 비교 후 v5를 별도로 검증했다. 현재 공통 기본 프로필로 v5를 연결한다.

요청한 표현·범위는 독립 AI 검토에서 **13/13 충족**, 전체 품질은 **11통과·2부분 충족**이다. v3/v4와 같은9문항은 v5에서7통과·2부분 충족이고, 추가4범위 사례는 모두통과다. 사람 검수·일반 정확도·서비스 전체 품질 승인은 아니다.

## 확인한 변화와 남은 문제

- 연봉·도움 범위: 내부 입력 중심의 관용적 서두와 작성규칙 선언이 사라졌다.
- 김치찌개·세그먼트 트리 일반 설명: 자료가 없다고만 말하지 않고 회사 업무 안내 서비스 범위를 알렸다.
- 같은 세그먼트 트리 질문에 합성 사내 운영 문서를 추가하자 해당 업무 사용법을 답했다. 기술어 자체의 차단이 아님을 이 사례에서 확인했다.
- 혼합 요청의 회사 업무 부분에는 답하고, 모호한 '트리'는 의미를 되물었다. 명시적 출처 요청에는 실제 제목을 유지했다.
- v4 U06은15분 목표를 대기 지시로 바꾸고 OR를 AND로 바꿔 미채택했다. v5의 해당1회는 두 관계를 보존했다. 안정적으로 해결됐다는 보장은 아니다.
- v5 U01은 퇴사 정산에 관한 People팀 책임을 일반 연봉 설명으로 확장했다. v3/v4에도 유사한 기존 문제이며 부분 충족이다.
- v5 U03은 연차 신청 후 팀장1영업일 회신을 누락했다. 같은 질문의 v3/v4에 있었으므로 이번 관측의 완전성 회귀다. 개선 목적이 충족됐다고 이 누락을 통과로 바꾸지 않는다.
- U09의 제도 운영 여부도 확인하기 어렵다는 문장은 다소 과잉 유보로 남는다.
