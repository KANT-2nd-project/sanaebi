# v3 최소 프롬프트 변경 검증

2026-10-15 사용자 후속 요청대로 v1에 **규칙 두 개만** 추가한 `examples_answer_scope_v3`를 구현했다. 초기24회 비교에서 내부 ID는 숨겼지만 신고 필수 입력 정보 누락이 남아 **초기 의미 검증을 통과하지 못했다. 현재 기본값은 v1을 유지한다.**

## 이번 변경과 관찰

v2의 예시·일괄 문서 진술 표현·타당성 검토 기능은 가져오지 않았다. v1의 정확한 system 접두부에 다음 두 규칙만 덧붙였다. 모델·추론·출력 모드·API·프런트엔드는 바꾸지 않았다.

- 내부 문서 ID·개정 번호를 답변에 표시하지 않고 필요하면 실제 제목·항목명으로 출처를 안내한다.
- 문서에 답이 있으면 일반 상식과 다르다는 이유로 작성 의도·타당성 추측을 붙이지 않는다. 질문에 필요한 정보 부족·조건·충돌 안내는 유지한다.

기존 모든 프로필과 v2는 해시로 보존했다. [후보 system 원문](candidate-system-prompt.txt), [입력·코드 해시](manifest.json), [호출 전 계획](../../experiments/answer-grounding-v3-20261015/protocol.json)을 참조한다.

## 실제 비교

모델 설정은 GPT-6 Luna / single / xhigh / 4096 / 180초 / prompt_json / temperature 생략이다. 실패 유형6개를 v1·v3 각2회 실행했다. 합계24/90회, 추정0.125989달러/5달러, 정상 JSON24/24, 미정산0·자동재시도0이다. 비용은 기존 보수적 함수의 추정이며 실제 청구액이 아니다.

| 확인 항목 | v1 | v3 |
|---|---|---|
| 정상 JSON | 12/12 | 12/12 |
| 출처 질문 내부 ID 노출 | 2/2 | 0/2 |
| 배포 실패 문구의 근거 없는 추가 의심 | 0/2 | 0/2 |
| 롤백 명령 부재 안내 | 2/2 | 2/2 |
| 신고 필수 정보 전체 보존 | 1/2 | 0/2 |
| 이해 상충 공개·검토 중 제한 | 2/2 | 2/2 |
| 상식과 다른 행동의 표현 변형 | 2/2 | 2/2 |

v3 신고 응답1은 실제 제출 불가·접수 경로·공개 채널 주의만 안내하고 시점·장소·행위·관련자 역할·목격자·보유 자료·보호/연락 정보를 모두 빠뜨렸다. 응답2는 대부분을 안내했으나 목격자·연락 방식이 빠졌다. v1도 두 번째 응답에서 목격자를 누락했다. 따라서 누락이 v3 규칙 때문에 발생했다고 단정하거나 v1의 품질을 보장하지 않는다. 다만 후보가 반드시 보존해야 할 정보를 안정적으로 안내한다는 근거가 부족하다.

예를 들어 v3 신고 응답1은 다음과 같았다.

> 제가 대신 포털에 신고를 접수할 수는 없습니다. 목격하신 분은 이음 포털의 **인사 > 상담·신고**에서 상담 요청 또는 공식 신고를 선택해 접수하실 수 있습니다. 공개 채널에는 당사자 이름, 사건 상세나 증거 원본을 올리지 마세요.

[문항별 발췌·판정](comparison.md), [구조화 검토](review.json), [집계](summary.json)에 근거를 보존했다. 원응답·원장은 `tmp/answer-grounding-v3/runs`에 둔다.

## 평가 기준의 한계

기존 G11 평가표는 사용자가 출처만 물었는데 항목명까지 필수로 요구한다. v3는 문서 제목만 표시해 ID 비노출 목표는 달성했지만, 고정표에 따라 부분 판정2건으로 보존했다. 이 기준은 과도할 여지가 있으며 이를 이유로만 채택을 보류하지 않았다. 원표 기준 통과는 v1 9/12·v3 8/12지만 이를 일반적인 품질 순위로 해석하지 않는다. **신고 정보의 실질적인 누락만으로도 초기 게이트가 실패한다.** 평가표를 사후 완화해 통과로 바꾸지 않았다.

구현 AI가 비블라인드로24개 응답을 읽고 문서·필수 주장과 대조했다. 독립 평가·사람 승인·새로운 정책 일반화 검증이 아니다. 이미 사용한 소규모 합성·업무 회귀 자료이며 반복2회로 모집단 실패율이나 인과관계를 추정하지 않는다. 원래의 불필요한 단서는 이번 v1에서도 재현되지 않았으므로 단서 발생률 감소를 주장하지 않는다.

## 실행하지 않은 단계와 결정

- v3 형식 실패가 없어 구조화 출력 후보의 사전 실행 조건이 충족되지 않았다. JSON 성공과 내용 완전성은 별개이며, 이번 누락을 해결했다는 근거 없이 strict로 바꾸지 않았다.
- 초기 의미 검증 실패로 확대 회귀·표현 변형 추가 실행·API/브라우저 확인·기본값 전환은 수행하지 않았다. 기존 v2 API 결과를 v3 검증으로 재사용하지 않았다.
- **v1 유지, v3 실험 후보만 보존.** 공개 서버 재시작·배포·실제 DB 변경은 하지 않았다.
- 다음 개선 검토 대상은 프롬프트 문구의 반복 추가보다, 문서상 필수 항목을 근거와 함께 추출하고 최종 답변의 누락을 확인하는 별도 흐름이다. 아직 채택·구현하지 않았다. 구조화 출력만으로 내용 완전성이 보장된다고 가정하지 않는다.

## 코드 검증

생성 관련257개와 전체 Python586개가 통과했다. legacy 평가 테스트의 DB 의존성 때문에 이전 단계에서 초기화한 빈 임시 SQLite를 `SANAEBI_DOCUMENT_DB`로 지정했으며 실제 DB는 쓰지 않았다. Ruff 검사·형식 검사를 통과했다. 기존 v1·v2 메시지의 동일성과 v3에서도 문서 ID·개정·본문이 모델 입력에 보존되는지 확인했다. 프롬프트 문자열 검사만으로 응답 품질을 주장하지 않았다.
