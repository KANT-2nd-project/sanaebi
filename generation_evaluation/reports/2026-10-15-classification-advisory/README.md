## 구현·보존·재현

순수 조합 함수 `generation.advisory.compose_advisory`와 평가 전용 실행기를 추가했다. 모든 라벨에 같은 지침·의미 설명을 제공하며 라벨 값만 다르다. 라벨 없음·알려진 오류·client 출처는 기존 프롬프트 객체를 그대로 반환한다. 기존 프로필 문자열과 공개 HTTP 계약은 변경하지 않았다. 런타임은 이 실험 helper를 호출하지 않는다.

[manifest](manifest.json)는 공개 문서 snapshot, 문항, 모델·프로필 설정, 고정 예측, classifier 파일 해시, 코드 및 184개 예정 메시지 해시를 보존한다. [원응답](responses.jsonl), [호출 사건](events.jsonl), [예산 장부](ledger.json), [요약](summary.json)을 함께 보존한다. 개인 문서·운영 DB·인증 정보는 포함하지 않는다. 사전 포맷 정리로 코드 해시가 바뀌어 첫 호출 전에 manifest를 다시 고정했고 이전 preflight manifest는 로컬 tmp에 보존했다. 예측은 다시 생성하지 않았다.

재현은 실행 코드 `56099f5` checkout을 사용한다. 최신 코드로 옛 결과를 resume하면 해시 불일치로 호출 전에 거부한다. 실패·불확실한 예약은 자동 재호출하지 않는다. `run --through 124`도 탐색 기준 미충족으로 거부한다. 후속 v6 코드 추가가 실험 도중 기준선을 바꾸지 않도록 평가 종료 후 main을 통합했다.
