# GPT-6 Luna 답변 범위·strict 출력 비교 결과

> 이 문서는 당시 실험 결과다. 이후 사용자는 범위 보강안을 최종 선택하고 튜닝을 종료했다. 현재 구성과 미완료로 종료한 범위는 [최종 결정](../../../docs/generation-final-prompt.md) 및 [기록 점검](../2026-10-15-luna-tuning-closure/README.md)을 따른다. 과거 점수·게이트 판정은 변경하지 않았다.

**두 후보 모두 개발 게이트에서 탈락했다. GPT-6 Luna 모델과 기존 기준 구성을 유지하며, 프롬프트·출력 모드 승격은 보류한다.** 개발 통과 수는 늘었지만 기준이 통과한 문항의 필수 안내를 빠뜨렸다. 사전에 정한 회귀 제외 규칙에 따라 반복 확인·조합·최종 20문항 실행은 생략했다. 이는 계획에 포함된 조기 종료이며 미완성 호출을 성공으로 처리한 결과가 아니다.

## 비교 조건과 결과

기준은 `examples / single / xhigh / prompt_json / 출력 4096 / timeout 180초 / temperature 생략`이다. `scope`는 최소 답변 범위 문단만 덧붙이고, `reference-strict`는 프롬프트를 그대로 두고 출력 모드만 변경했다. 모델은 모두 GPT-6 Luna다.

| 후보 | 통과 / 부분 / 실패 / 불확실 | 중대 오류 문항 | 형식 오류 | 지연 중앙값 / 최대 | API 추정 비용 |
|---|---|---:|---:|---:|---:|
| reference | 9 / 3 / 0 / 0 | 0 | 0 | 4.76 / 18.57초 | $0.176693 |
| scope | 11 / 1 / 0 / 0 | 0 | 0 | 5.39 / 7.02초 | $0.174610 |
| reference-strict | 11 / 1 / 0 / 0 | 0 | 0 | 8.60 / 17.98초 | $0.176252 |

각 후보는 같은 개발 12문항을 1회 실행했다. 두 반복 모두 통과한 문항 수와 반복 안정성은 **미측정**이다. 집계 JSON의 `stable_both_pass_case_count=0`은 두 반복을 실행하지 않아 생긴 구조적 값이며, 안정적으로 통과한 문항이 없다는 관측 결과가 아니다.

개발 36호출과 strict 호환성 2호출을 합쳐 **38/166회**, 추정 비용 **$0.528206**을 사용했다. 미정산 요청·자동 재시도는 없었다. 금액·전체 시간 한도는 두지 않았으며 비용은 보수적인 장문 입력 단가에 따른 추정으로 청구서 확정액이 아니다. [공식 가격표](https://developers.openai.com/api/docs/pricing)를 확인한 기준이며 세부 사용량과 원장 해시는 [실행 기록](execution.json)에 있다.

| 후보 | 입력 토큰 | 출력 토큰 | 출력에 포함된 추론 토큰 |
|---|---:|---:|---:|
| reference | 687,998 | 6,260 | 4,570 |
| scope | 689,786 | 6,429 | 4,692 |
| reference-strict | 688,298 | 5,572 | 3,851 |

이번 36응답에서 형식·근거·조건/적용 범위·과잉 유보·권한 경계·한국어 존댓말·관련성 차원은 모두 통과했다. 완전성에서만 총 5응답이 부분 충족이었다. 이는 이번 고정 문항에서의 AI 판정이며 일반 정확도나 안전성 보증이 아니다.

## 개선과 탈락 이유

기준은 개발 01의 요청 유형, 05의 문의 경로, 10의 상담/신고 구분을 빠뜨렸다. 두 후보는 이 세 문항을 모두 통과했지만 **개발 09에서 새 누락**이 생겼다.

- 기준: 신고 시 관련자 역할·목격자·보유 자료를 모두 적도록 안내했다.
- scope: 관련자 역할과 보유 자료는 안내했으나 목격자 정보를 적으라는 안내가 없었다. “목격한 범위”는 관찰 범위 표현이며 목격자 정보 안내와 같지 않다.
- reference-strict: 관련자 역할·목격자·보유 자료 안내를 빠뜨렸다.

근거 `ieum-063`은 신고에 가능한 범위에서 이 정보를 적도록 한다. 고정 [프로토콜](../../experiments/luna-reference-followup-v1/protocol.json)은 필수 안내의 명확한 회귀를 제외 조건으로 정했으며, 총 통과 수 증가로 상쇄한다고 정하지 않았다. 독립 AI의 [게이트 재검토](gate-audit.json)도 같은 결론이었다. 따라서 적격 최선 후보가 없고, 반복 확인이나 조합으로 다시 적격성을 얻으려는 호출은 하지 않았다.

strict 옵션의 실호출 호환성은 확인됐다. 다만 일반 모드도 이번에 형식 오류가 없었으므로 **측정된 형식 정확도 향상은 없다**. strict가 JSON 구조를 제한한다는 사실은 내용의 완전성을 보장하지 않으며, 이번에는 중앙 지연도 더 컸다. 구현은 선택 가능한 옵션으로 유지하되 실험 권장 구성이나 서비스 기본값으로 채택하지 않는다.

## 판정과 한계

후보명을 가린 별도 AI가 응답 36개를 판정했고, 부분 충족 5건을 원문 근거로 재검토했다. 개발09는 포털 또는 #people-help 중 한 경로면 충분한데, 최초 판정 하나가 두 경로를 요구했다. 이 오판정 이유를 정정했으며 다른 필수 정보 누락 때문에 최종 부분 충족은 유지됐다. [정정 기록](development-adjudications.json)을 보존했다. 사람 검수나 승인이 아니다.

개발10은 잘못된 전제를 부정하는 것 외에 상담/정식 신고 구분까지 고정 필수 주장에 포함했다. 질문에 필요한 범위보다 넓을 수 있어 **이 문항의 개선을 실제 유용성 향상으로 과대해석하지 않는다**. 결과를 보고 루브릭이나 점수를 바꾸지는 않았다.

자료32개 중 기존 AI 검수 `SEARCH_KNOWLEDGE` 원문은 6개이고 합성은 26개다. 실제 사용자 발화 자료가 아니며, 미사용 질문 전체의 대체 가능성을 전수 조사하지 않았다. 같은71개 정책 문서를 공유하므로 독립적인 정책 주제32개로 일반화할 수 없다. 최종 선정20문항은 생성 미실행 상태로 보존했고, 18/20 두 반복 통과라는 승격 기준은 평가하지 않았다.
