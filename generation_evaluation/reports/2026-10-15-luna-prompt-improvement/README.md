# GPT-6 Luna 프롬프트 강화 실험 — 개발 평가 완료·최종 평가 준비

선택 모델 GPT-6 Luna의 examples/single/xhigh/출력4096을 기준으로 프롬프트 후보만 변경한다. 새 승인 한도는2시간·API3달러이며 개발 우선 배정은70분·1.2달러다. 이전 실험 원장을 초기화하지 않고 별도 실험으로 기록한다. 이후 사용자가 비용 제한을 철회했으며 시간2시간은 유지한다. 현재3달러 운영 상한은 충분하여 원장·시계를 바꾸지 않고 사용한다.

기준·필수 안내 점검·조건 연결·JSON 예시를 순서대로 비교한다. 두 차례 연속 개선이 없으면 추가 튜닝을 멈춘다. 기존 개발8문항은 필수 주장 자체를 유지하고 역할 태그와 의미 동등성 판정 해석을 호출 전에 고정했다. 새 최종20문항은 독립 작성·검토 후 고정하며 결과를 본 뒤 튜닝하지 않는다.

호출 비용은 [사전 상계](preflight.json)로 예약하고 실제 사용량이 있으면 보수적 단가로 정산한다. 이는 청구서가 아니다. 캐시 적중 차이와 출력 길이를 함께 기록한다. 전체 한도 및 이전 원장 식별은 [실행 승인 기록](authorization.json)을 따른다.

공식 [GPT-6 Luna 모델 안내](https://developers.openai.com/api/docs/models/gpt-6-luna)와 [가격표](https://developers.openai.com/api/docs/pricing)를 실행 전에 확인했다. [GPT-6 프롬프트 가이드](https://developers.openai.com/api/docs/guides/latest-model)의 일반 지침을 해당 모델·업무에서 실험해야 하며, 일반 지침을 이 프로젝트 성능 향상 근거로 취급하지 않는다.

개발 기준8응답 완료 후 공용 원장 한도를 다른 출력 폴더에서도 고정하도록 실행기만 보완했다(2518e78). 기준 프롬프트·모델·입력은 바꾸지 않았고 완료된 기준 호출을 재호출하지 않았다. 이후 후보의 manifest에는 새 실행 코드 hash가 기록된다. 예산·호출 계약 검증용213개 테스트가 통과했다.

개발 판정의 일관성 재검토에서 RQ0007의 ‘실제 지출을 추정하지 말 것’을 분실 사실의 정직한 표시와 별도 의미로 적용했다. 기준과C1 모두 이 문구의 의미가 빠져 같은 부분 충족으로 정정했다. 문서 원문은 분실 사실·대체 증빙을 직접 설명하므로 개발 필수 기준이 더 강하다는 한계를 기록한다. 결과를 본 뒤 필수 기준을 삭제하거나 한 후보에만 완화하지 않았다. 새 최종 세트에서는 질문에 필요한 최소 주장과 선택적 배경을 사전에 구분한다.

## 이번 게시 시점의 확인된 상태

개발48응답의 기준·후보·원응답·독립 판정·재판정 근거를 보존했다. 기준은 두 반복 통과11/16·안정 통과5/8, 필수 안내 점검 후보는13/16·안정 통과6/8이다. 조건 연결·JSON 예시는 각각 첫8응답에서6개·5개 통과로 최선 후보를 개선하지 못해 추가 튜닝을 멈췄다. 최종 후보는 luna-coverage이며 아직 채택하지 않았다.

새20문항과 기준·coverage 각2회(예정80응답) 비교 조건은 frozen-final.json에 고정했다. 이번 게시에서 최종 호출 결과는 없으며 개발 성적을 최종 개선 효과로 표현하지 않는다. 선택 모델 GPT-6 Luna는 유지한다. 현재 확인한 생성 테스트213개·전체Ruff·형식240파일 검사를 통과했다. [게시 작업 일지](../../../docs/worklogs/2026-10-15-luna-prompt-publication.md)를 따른다.
