# 추론 확장 후 최종 선정

**두 후보의 상대 비교 결과 GPT-6 Luna를 선택했다. 후속 기준 구성은 examples / single / xhigh / max_output_tokens=4096이다.** temperature는 전달하지 않는다. Qwen3 4B Q4_K_M은 examples / single, 출력 1024, 문맥 98304, temperature 0, seed 42다. 두 모델 모두 기본 설정 승격·서비스 품질 승인은 보류한다.

## 모델 선택 확정 — 2026-10-15 사용자 결정

이번 모델 선정의 기준은 **Qwen3 4B Q4_K_M과 GPT-6 Luna 중 상대적으로 더 좋은 모델을 고르는 것**이다. 사전 비교 순서와 관측 결과에 따라 **GPT-6 Luna를 선택했다.** 이후 개선은 GPT-6 Luna 기반으로 진행한다. 18/20 기준은 두 후보 중 선택을 취소하는 조건이 아니라 기본 설정 승격·서비스 품질 판단을 위한 별도 목표로 구분한다.

앞선 보고서의 ‘잠정 권장’은 당시 표현이며, 이번 사용자 확인으로 모델 선택을 확정했다. 점수·문항·판정·실험 당시 기준은 변경하지 않는다. 선택 모델은 GPT-6 Luna, 후속 기준 구성은 examples/single/xhigh/출력4096이며 CLI·서버 기본값은 이번 문서 결정만으로 변경하지 않았다. [후속 프롬프트 강화 준비](../../../../docs/generation-luna-prompt-improvement.md)를 따른다.

## 사전 기준과 결과

출력 형식, 문서 근거, 적용 범위·조건, 필수 안내 완전성, 적절한 유보, 조회·실행 권한 경계, 말투, 질문 관련성의 8개 차원을 먼저 고정했다. 문항별 필수·금지 주장과 정확한 원문 구간으로 판정했다. 모델 정보를 가린 AI 독립 검토와 원문 기반 경계 재검토를 수행했다. 사람 업무 담당자의 승인이나 운영 정확도 검증은 아니다.

| 지표 | GPT-6 Luna xhigh | Qwen3 4B Q4_K_M |
|---|---:|---:|
| 전체 응답 | 40 | 40 |
| 통과 / 부분 충족 / 실패 / 불확실 | 25 / 15 / 0 / 0 | 0 / 26 / 14 / 0 |
| 중대한 오류가 발생한 문항 | 0/20 | 5/20 |
| 두 반복 모두 통과 | 11/20 | 0/20 |
| 형식·생성 실패 | 0 | 5 |
| 반복 간 판정 변화 문항 | 3 | 0 |
| 응답 시간 중앙값 / 최대 | 12.09 / 26.81초 | 32.80 / 161.46초 |

중대한 오류 문항 수 → 두 반복 통과 문항 수 → 전체 통과 수 → 불확실 수 → 시간 → API 비용 순서로 선정했다. GPT를 선택했지만 두 반복 통과 18/20 이상·중대한 오류 0이라는 승격 기준을 충족하지 못했다. Qwen의 통과 0은 모든 답이 틀렸다는 뜻이 아니다. 26응답은 일부 정보를 맞혔으나 사전 필수 안내를 빠뜨렸다.

## 남은 오류와 해석

GPT는 40응답 모두 출력 형식·문서 근거·적용 조건·말투 검사를 통과했지만 15응답에서 필수 안내가 부족했다. 출장 금액 증가 시 재승인, 경비 승인·기한·금액 기준 등 문항별 세부 조항을 함께 담는 문제가 남았다. 일부 필수 기준은 질문에서 직접 묻지 않은 조건부 안내까지 요구한다. 평가 후 완화하지 않고 결과와 이 한계를 함께 남긴다.

Qwen의 중대한 오류는 출입 카드 발급 승인 경로, 유출 자료의 즉시 삭제, 조직 역할 조회에 퇴사 절차 적용, 예약 변경의 포괄적 불인정 정책 생성, 긴급 권한의 승인·기간 왜곡 등이다. 기술 실패 5회는 제공자 ResponseError 3회와 잘림 2회다. 자동 재시도나 답변 대체는 하지 않았다. [문항별 원응답·근거](comparison.md), [경계 재판정](adjudications.json)을 함께 확인한다.

Qwen은 이번 40회 모두 실제 GPU 35/37층 배치였다. 시작 시 다른 로컬 모델과 메모리 경합이 있었고 이후 경합이 사라져도 실행 중 배치를 바꾸지 않았다. 이전 전용 실행의 37/37층·약18 TPS와 직접 비교해 속도 퇴행이라고 결론내릴 수 없다. 이번 평가 종료 후 평가 전용 모델과 서버를 정리했다. [실행 환경](runtime.json)을 보존한다.

## 개선 효과와 탈락 후보

같은 개발 8문항의 두 반복 통과 수는 기존 none 4/8 → high 5/8 → xhigh·4096 6/8이었다. xhigh·1024는 추론 토큰 때문에 잘림이 발생해 탈락했다. max는 현재 Chat Completions 호출 경로에서 unsupported_value HTTP400으로 실패했다. 공식 문서의 모델 지원 목록과 이 호출 경로의 실제 수용 여부를 구분한다. 근거 추출 후 답변은 정확한 인용 검증만으로 근거 누락을 막지 못해 채택하지 않았다.

새 최종 20문항은 13개 기존 SEARCH_KNOWLEDGE 합성 데이터와 7개 추가 합성·변형 사례로 구성했다. 정상 8, 자료 부족 4, 조건·범위 4, 권한 2, 잘못된 전제 2다. 개발·1차 선정 질문 그룹과 분리하고 실행 전에 고정했다. 1차와 질문이 다르므로 두 최종 점수의 차이는 직접적인 개선 효과가 아니다. 작은 합성 세트, AI 판정, 문서 71건 snapshot에 한정된 선정 근거다.

## 비용과 재현

최신 GPT 최종 40회 입력 2,293,492토큰, 출력 36,421토큰(추론 27,903 포함)이다. 표준 단가·확인된 사용량 추정은 $0.17302511, 보수적 예산 계산은 $0.33694497이다. 캐시 적중과 호출 순서가 달라 후보별 관측 비용을 일반적인 가격 우위로 해석하지 않는다. Qwen API 과금은 없으며 로컬 전력·장비 비용은 산정하지 않았다.
