# 최종 Luna 독립 실행 연결 검증

품질 재평가나 튜닝이 아니라, 사용자 채택 구성을 두 CLI에 연결한 검증이다. 실제 호출은 단일 생성 1회와 배치 limit=1의 1회, 총 2회이며 재시도하지 않았다.

동일 RQ0001·71문서에서 config/documents_sha256/prompt_sha256이 일치했다. 단일 생성은 completed/stop·14.04초·입력57483/출력687토큰, 배치는 parse_error/stop·7.02초·입력57483/출력602토큰이었다. 배치 응답은 일반 문장이라 answer=None·종료 코드1로 보존했다. JSON 자동 보정·strict 대체는 하지 않았다.

기존 budget.actual_cost의 보수적 단가와 관측 입출력 토큰으로 추정한 비용은 단일 $0.014886, 배치 $0.01482225, 합계 $0.02970825다. 캐시 세부 정보가 없는 실행 기록으로 계산한 추정이며 실제 청구 금액이 아니다.

[원응답·설정·사용량·시간·비용](results.json)과 [입력 확인](manifest.json)을 보존한다. 동일 문항 2회로 일반 정확도·반복 안정성을 판단하지 않는다. prompt_json의 형식 실패 가능성이 실제로 관측됐으며 서비스 품질 승인으로 취급하지 않는다. 알려진 필수 안내 누락도 해결됐다고 주장하지 않는다.
