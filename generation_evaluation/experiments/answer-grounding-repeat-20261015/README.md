# 답변 누락 반복 비교

사용자의 “두 번 차이는 오차범위 아닌가”라는 후속 요청에 따른 재검증이다. 프롬프트·모델·문서·추론 설정을 변경하지 않고 v1/v3를 비교한다. 기존 2회 결과는 새로운 표본에 합치지 않는다.

호출 전에 [protocol.json](protocol.json)을 고정했다. 신고 문항 DEV-FU-09는 각40회, 출처 문항 G11은 각5회로 총90회다. 반복마다 프로필 순서를 고정 난수로 섞고 순차 실행한다. 재시도와 품질에 따른 조기 종료는 없다. 예산은 기존 실험과 별도의 원장으로 추정5달러를 제한한다. 기존 회귀 12문항 전체를 반복한 실험이 아니다.

주 지표는 기존 엄격한 체크리스트의 완전성이다. 정상 응답·제출 불가·정확한 경로와 시점/장소/행위/관련자 역할/목격자/보유 자료/보호/연락이 모두 있어야 한다. 각 필드도 별도로 기록한다. “목격한 상황”만 언급한 것을 목격자 입력 안내로 세거나, 공개 채널에 증거를 올리지 말라는 경고를 보유 자료 입력 안내로 세지 않는다. 동의 표현은 의미로 판단한다. AI가 전체 응답을 근거와 대조하며 사람 승인이나 블라인드 검토로 표현하지 않는다.

**추가 민감도 분석:** 실행 시작 후 초기5개 응답을 본 시점에 원문의 “원하는 보호나 연락 방식”을 재확인했다. 보호와 연락을 모두 요구하는 기존 기준이 과도할 수 있어, 둘 중 하나만 있어도 인정하는 완화 결과를 별도로 산출한다. 사전 주 지표를 바꾸지 않으며 이 추가 분석은 사전 등록 분석으로 표현하지 않는다. 출처 항목은 질문에서 요구하지 않은 항목명을 필수로 두지 않는다.

비율의 Wilson95% 구간과 양측 Fisher 정확검정을 사용한다. 비유의성을 동등성의 증거로 해석하지 않는다. 동일 질문의 생성 변동을 측정할 뿐 실제 사용자 질문 모집단의 품질이나 장기 안정성을 증명하지 않는다. 모델 백엔드·시간대 변화나 호출 간 상관을 통제할 수 없으므로 통계량은 독립 시행 근사 아래 해석한다.

```bash
PYTHONPATH=. uv run --locked python generation_evaluation/experiments/answer-grounding-repeat-20261015/run.py \
  --env-file /path/to/private.env --output tmp/answer-grounding-repeat/runs
```

원응답·설정·해시·사용량·지연·오류·예약 원장은 `tmp/`에 남긴다. 공개 보고서에는 합성 문서 기반 답변과 판정·해시를 보존한다. 실제 DB·비공개 문서·인증정보는 사용하거나 게시하지 않는다. 서비스 기본값 승격은 이 반복 비교의 자동 결과가 아니다.

방법 참고: [NIST 비율 신뢰구간](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm).
