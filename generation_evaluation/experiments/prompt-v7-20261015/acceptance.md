# v7 사전 결정 기준

승인된 계획: 독립 효과 비교 12×3=36, 두 후보가 각각 유지 가치가 있을 때만 결합12, 확정후보와 v5의 신규 선정12×2×3=72. 공유 최대120 생성 시도. 자동 재시도·추가 튜닝·서버 재시작·배포 없음.

가독성 후보: 공통 가독성 또는 지정 구조 준수가 개선되고 내용·조건·필수 안내에 새 퇴행이 없어야 유지한다. 완전성 후보: 필수 주장 누락이 감소하고 중대한 오류·불필요한 안내·형식 실패가 늘지 않아야 유지한다. 한 개도 통과하지 못하면 최종 비교를 생략하고 v5를 유지한다.

최선 후보 순서: 중대한 오류 수 → 필수 주장 누락 수 → 전체 내용 통과 수 → 구조 준수 → 공통 가독성 → 지연 → 비용. 개발은 같은 문항의 주장별 v5 대비 퇴행도 비교한다. combined는 독립 후보의 개선을 보존하는지 검토하고, 새 퇴행이면 탈락시킨다.

기본값 승격은 다음 조건 모두를 만족해야 한다.

1. 중대한 근거·권한·허구 실행 오류와 JSON·API 실패 없음.
2. 12문항 중 최소11문항이 세 반복 모두 내용 통과.
3. 사고 대응2문항은 모든 반복에서 필수 안내 충족.
4. v5가 세 번 모두 통과한 문항에 신규 내용 실패 없음.
5. 도움소개2문항은 모든 반복에 소개·업무 불릿·실행 한계 구분.
6. 조건부 대안의 잘못된 순차화와 단답·거절·재질문의 불필요한 서식 없음.
7. 독립 검토 미해결 차단 사유 없음.

pass/partial/fail/uncertain을 구분한다. partial/uncertain은 pass로 집계하지 않는다. 공통 가독성과 지정 구조 준수를 후보에 무관하게 별도로 판정한다. 내용 실패는 문서와 질문에서 정한 필수 주장 기준으로 판정하며 프롬프트를 근거 삼아 회사 정책을 만들지 않는다. API·잘림·파싱 실패는 분모에 유지한다.

도움 소개는 계획상 개발과 선정에 모두 포함되며 프롬프트 예시에서도 같은 상위 과제를 보여준다. 선정의 구체적 대상/업무 시나리오는 분리하지만 이2문항을 의도 미노출 평가로 표현하지 않는다. 나머지도 AI 작성·판정 소표본으로 운영 신뢰성 증명이 아니다.

개발 결과를 보기 전에 두 세트와 근거/루브릭을 고정한다. 선정 응답을 본 뒤 프롬프트·평가 기준을 바꾸지 않는다. 근거 없는 주장 판정은 전체72문서 snapshot을 확인하고 초기·정정 판정을 모두 보존한다.
