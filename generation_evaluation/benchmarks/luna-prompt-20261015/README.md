# GPT-6 Luna 최종 비교 평가 자료: 프롬프트 강화 후

`final.json`은 프롬프트 강화를 마친 뒤 GPT-6 Luna의 기준 프롬프트와 선택 후보를 비교하기 위한 고정 20문항 최종 평가 세트다. 프롬프트 튜닝에는 사용하지 않는다. 이 20문항은 현재까지 어떤 모델에도 호출하지 않았다. 기존 개발·선정 문항 및 응답 기록을 근거로 가져오지 않았으며, 문항·근거·요구 주장·판정 범위를 최종 호출 전에 고정한다.

## 질문 출처와 비중복

`SEARCH_KNOWLEDGE` 질문군 8개를 활용했다. `RG0183`, `RG0032`, `RG0094`는 원 질문군을 유지했다. `RG0169`, `RG0236`, `RG0254`, `RG0262`, `RG0269`는 문서가 실제로 답할 수 있는 범위로 질문을 좁히거나 바꿔 `synthetic_adapted`로 표시했다. 나머지는 71개 문서 스냅샷에 맞춰 만든 합성 사례다. 예시로 사용하는 원래 질문군과 `group_id`는 모두 기존 `selection-20261015/dev.json`, `final.json`, `reasoning-final.json`의 48개 그룹과 겹치지 않는다. 최종 20개 `group_id`도 모두 서로 다르다.

의미 중복 검토에서 경비 제출과 기존 경비 기한 질문, 구매 승인·금액 구간, 퇴사 자산 반납, 장비 보증·수리, 출장 변경·영수증 분실, 방문자 등록, 배포 긴급 변경, 구매 분할 승인 및 임시 관리자 권한 문항은 제거했다. 남긴 질문도 같은 질문을 다른 표현으로 반복하지 않도록 직접 요구와 적용 조건을 구분했다.

## 판정 기준

각 사례의 `required_claims`는 질문에 직접 답하거나 결론을 바꾸는 조건만 담는다. `optional_context`는 답변에 도움이 될 수 있지만 질문의 결론에 필수적이지 않은 안내다. 선택 안내를 빠뜨렸다는 이유만으로 필수 주장 누락을 판정하지 않는다. `required_claim_types`는 같은 순서의 주장에 대응하며 허용 값은 다음 세 가지다.

- `direct_request`: 질문이 직접 묻는 답이나 요청의 처리 경계
- `decision_condition`: 예외·조건·적용 범위 중 답의 결론을 바꾸는 내용
- `action_guidance`: 질문에 답하기 위해 필요한 공식 절차 또는 다음 행동

평가자는 다음 항목을 독립적으로 확인한다. `format`은 요구된 JSON 응답 계약과 파싱 가능성, `grounding`은 문서 밖 정책·권한·사실을 만들지 않았는지, `scope_conditions`는 조건·예외·대상 범위를 보존했는지, `completeness`는 필수 주장만 빠짐없이 답했는지, `abstention`은 자료 부족을 인정하고 안전한 확인 경로를 제시했는지, `action_boundary`는 신고·승인·변경을 실제 완료했다고 가장하지 않았는지, `style`은 요청한 한국어 말투와 명료성을 지켰는지, `relevance`는 질문에 필요한 내용에 집중했는지를 본다.

문항별 결과는 통과·부분 충족·실패·불확실로 기록한다. 인용, 메뉴, 담당 역할, 금액, 기한, 실행 완료를 꾸며낸 경우는 별도 근거 오류로 표시한다. 불확실을 통과로 올리지 않으며 경계 판정은 인용한 원문과 다시 대조한다. M03은 부분 답변으로 고정했다. 직무교육 지원 한도와 합격 포상 미보장은 확인되지만, 특정 자격시험 응시료의 지원 여부는 명시되지 않으므로 일반 500,000원 한도를 시험 한도로 강제하거나 추정하지 않는다. M03은 기존 직무교육 지원 정책(ieum-049, ieum-053)과 인접하고 그 정책 근거를 일부 공유하므로, 독립적인 업무 분야 일반화의 증거로 해석하지 않는다. 이 문항은 시험 응시료 환급·합격 포상으로 직무교육 기준을 잘못 확장하는지와 확인 가능한 범위를 구분하는지만 평가한다.

## 근거와 합성 사례

인용한 37개 문구는 `tmp/generation-selection-20261015/documents.jsonl`의 71개 문서 본문에서 정확한 연속 부분 문자열로 확인했다. 질문별로 필요한 주장만 근거에 연결했다. 합성 부족 사례는 문서에 정책이 있다고 주장하는 예시가 아니다. 관련 제도가 문서 스냅샷에서 확인되지 않으면 확인 불가라고 답하고, 공식 저장소와 해당 소유 역할에 문의하는 답을 평가한다.

부족 문항에서 검색한 주요 표현군은 다음과 같다.

- 헬스장·헬스클럽·피트니스·체육시설·회원권
- 보육비·보육시설·어린이집·아이돌봄·자녀 돌봄 비용
- 자격시험·자격증 시험·응시료·환급·시험 포상금·합격 포상금
- 유급 봉사휴가·봉사활동 휴가·자원봉사 휴가·봉사휴가

검색 결과는 이 71개 문서 스냅샷에서 해당 지원 기준을 찾지 못했다는 범위만 말한다. 다른 회사 문서나 별도 시스템에 정책이 없다는 뜻은 아니다. `ieum-055`의 문서 탐색 안내와 `ieum-053`의 역할·문의표를 따라 추가 확인하도록 한다. M03은 교육 제도의 일반 기준이 일부 확인되므로 완전한 자료 부족으로 처리하지 않고 `partial`로 둔다.
