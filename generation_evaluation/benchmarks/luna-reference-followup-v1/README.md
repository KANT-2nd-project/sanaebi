# GPT-6 Luna reference follow-up benchmark v1

이 묶음은 GPT-6 Luna 프롬프트 후속 실험의 **개발 12문항**과 **봉인 선정 20문항**입니다. 최종 모델 응답을 받기 전에 질문, 필수·금지 주장, 자료 범위와 판정 기준을 고정합니다. `rubric.json`은 독립 AI 검토에서 `PASS_WITH_LIMITATIONS`를 받아 데이터셋을 동결했습니다. 이 표시는 사람 승인이나 미사용 실제 질문 전체의 전수 검토를 뜻하지 않습니다.

## 구성과 경계

- `dev.json`: 개발·회귀 문항 12개.
- `holdout.json`: 선정 문항 20개, 정상 답변 8 / 부분·자료 부족 4 / 조건·예외 4 / 권한·실행 2 / 잘못된 전제 2.
- `rubric.json`: JSON 출력, 근거성, 범위·조건, 필수 답변 완전성, 부분 답변, 권한 경계, 말투, 관련성 판정 기준.
- 각 사례는 필수 주장에 필요성 이유를 기록합니다. `optional_background`는 빠져도 감점하지 않으며, `absence_checks`는 고정 snapshot 안에서 찾지 못한 사실만 다룹니다.

기존 `SEARCH_KNOWLEDGE` 자료 중 개발 2개와 선정 4개를 원래 질문 ID·그룹 ID·출처와 함께 보존했습니다. 이 자료는 데이터셋의 AI 검수 라우팅 질문이며 실제 고객 발화로 간주하지 않습니다. 나머지 사례는 특정 문서 조건, 부분 답변, 실행 권한 또는 잘못된 전제를 평가할 유형을 기존 선택 문항에서 찾지 못해 보충한 합성 사례입니다. 각 사례의 `provenance.reason`은 보충 이유를 구체적으로 기록하며, 미사용 질문 전체에 유사 의도가 전혀 없다고 주장하지 않습니다. 일부 실제 질문은 근거가 부족하다는 이유로 정상 답변 유형으로 올리지 않았습니다.

개발·선정 사이와 앞선 평가 세트 및 프롬프트 예시 사이에서 의도 그룹을 재사용하지 않습니다. 후보 프롬프트 문구는 조사 계획에서 동결된 상태이며, 이 자료는 후보별 모델 호출을 보기 전에 독립 검토되어야 합니다. 응답 판정은 AI 블라인드 검토이고 사람 검수로 표현하지 않습니다.

## 문서 근거와 재현성

문서 원본은 앞선 실험의 고정 snapshot으로, SHA-256은 `d58dc0ab1d40bdb9fff68362dc4f5a241fb34ac7fee92f551851d933c1adde74`입니다. 각 근거 구절에는 문서 ID, 제목, revision, 본문 해시, 제목 기준 위치와 문자 오프셋이 있습니다. snapshot의 71개 본문은 저장소의 `data/company-knowledge/documents.jsonl` 본문과 바이트 단위로 같습니다. 저장소 본문 파일 SHA-256은 `84b44e6592e3a6bd883b7890239aada11382cbef9a369ebb0aca3b15defddfe4`입니다. snapshot JSONL 직렬화 해시는 저장소 파일의 직렬화 해시와 다르므로, 코퍼스 해시와 snapshot 해시를 서로 바꿔 쓰지 않습니다.

`absence_checks`는 71개 snapshot 범위에 한정된 부재 확인입니다. 해당 정보가 회사의 다른 정책·문서에도 없다고 확대 해석하지 않습니다. 임시 snapshot 경로가 없는 체크아웃에서도 근거 인용 검증이 가능하도록 본문 검사는 저장소의 고정 코퍼스를 기준으로 합니다.

## 실행 전 확인

1. 독립 AI 검토 결과와 한계를 `independent-review.json`에서 확인합니다.
2. 품질 호출 전에 최종 후보와 실행 설정을 동결합니다.
3. `generation_evaluation.selection`에 `--rubric generation_evaluation/benchmarks/luna-reference-followup-v1/rubric.json`을 전달합니다.
4. 후보 작성·선정 담당자는 후보 동결 전 holdout을 열람하지 않습니다. 작성자와 독립 검토자는 동결 전에 평가 자료의 품질을 검토합니다. 실행 후 수정이 불가피하면 이전 결과를 선정 증거로 사용하지 않고, 새 버전과 새 실행 ID로 다시 평가합니다.
