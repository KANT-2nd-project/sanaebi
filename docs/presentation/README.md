# 사내비 프로젝트 발표

[발표 PDF — 개정2](sanaebi-project-revised2.pdf) · [프로젝트 소개](../../README.md)

가상 회사 이음웍스의 개발 담당자가 서비스를 소개하는 형식으로 구성한 **프로젝트 발표자료**입니다. 실제 기업의 출시 발표나 실직원 조사 결과가 아닙니다. 본문 17장과 부록 6장으로 문서 준비 → 분류 → 검색 → 생성의 구현 이유와 비교 결과를 설명합니다.

발표는 2026-10-16 작성 당시 기록을 바탕으로 합니다. 이후 채택·배포 상태의 기준은 [서비스 설계](../service-architecture.md)와 [최종 생성 구성](../generation-final-prompt.md)이며, 발표의 고정 실험 결과를 현재 서비스 종합 성능으로 해석하지 않습니다.
