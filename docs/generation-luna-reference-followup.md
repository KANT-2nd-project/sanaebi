# GPT-6 Luna: 답변 범위와 구조화 출력 후속 비교

GPT-6 Luna를 선택 모델로 유지하면서, 부분 답변·필수 안내를 보완하는 최소 프롬프트 변경과 JSON Schema 출력 옵션을 비교한다. 이전 프롬프트 개선 실험은 당시 결과와 중단 상태를 보존하며, 이 실험과 점수를 합치지 않는다.

## 구현된 계약

`examples_answer_scope_v1`은 기존 `examples`에 답변 범위 문단만 추가한다. 과거 프로필은 변경하지 않는다. 전체 시스템 프롬프트 교체안은 이번 후보에 포함하지 않는다.

`GenerationConfig.output_mode`는 과거 설정에 필드가 없어도 `prompt_json`으로 읽는다. `strict_json_schema`는 OpenAI Chat Completions 전용이며, 이름이 있는 strict JSON Schema로 문자열 `answer` 한 키만 허용한다. 일반 모드의 신규 파싱도 추가 키를 `parse_error`로 판단한다. 공백 답변은 기존 `empty_answer`다. 과거 저장 기록은 새 파서로 다시 판정하지 않는다.

명시적 모델 거절은 `refusal`과 별도 거절 정보로 보존하고 `answer=None`으로 반환한다. 거절 → 잘림 → 정상 파싱 순으로 판단하며, timeout/API 오류를 답변으로 바꾸지 않는다. strict 지원 오류 시 일반 모드로 자동 대체하거나 재시도하지 않는다.

설치된 LangChain의 자동 구조화 파싱은 잘림 시 원응답을 반환하기 전에 예외를 던질 수 있다. 공통 호출 함수는 Chat Completions의 원응답을 받은 뒤 원래 `AIMessage`로 변환하여 원문·사용량·종료 사유·거절을 보존한다. 이 경로는 설치 버전의 전송 mock과 실호출로 확인한다. 라이브러리 내부 변환 함수를 사용하므로 의존성 갱신 시 해당 테스트가 필요하다.

## 실행과 평가

[고정 후보·프로토콜](../generation_evaluation/experiments/luna-reference-followup-v1/README.md)과 [새 평가 자료](../generation_evaluation/benchmarks/luna-reference-followup-v1/)를 사용한다. 기준 구성은 `examples / single / xhigh / 4096 / 180초`, temperature 생략이다. 서버의 기본값을 자동 변경하지 않는다.

`generation_evaluation.selection`에서 `--rubric`을 별도로 읽으며 모델 입력에는 넣지 않는다. manifest는 자료·루브릭·후보 설정과 파서·결과 타입·직렬화·출력 스키마·의존성 잠금 파일을 추적한다. 같은 실행의 재개 시 이 내용이 달라지면 거부한다.

이번 원장은 금액·전체 시간 제한 없이 최대 166회 호출을 공유한다. 호출 전에 원자적으로 예약하며, 실패한 호출도 센다. 사용량을 받지 못하면 비용을 0으로 확정하지 않고 예약 추정액을 유지한다. 결과가 저장된 성공·실패는 재호출하지 않으며, 시작 기록만 있는 요청도 자동 재실행하지 않는다. 과거 유한 한도 원장의 의미는 유지한다.

평가에서는 형식·한국어 존댓말·관련성, 문서 근거, 대상·주체·조건·예외, 필수 안내, 부분 답변·과잉 유보, 허구의 권한·메뉴·처리 완료·지급 보장을 구분한다. 후보명을 가린 독립 AI 검토와 근거 재검토를 수행하며 사람 검수로 표현하지 않는다.

선정 순서는 중대한 오류 문항 수, 두 반복 모두 통과한 문항 수, 전체 통과 수, 불확실 수, 지연, 비용이다. 두 반복 모두 통과 18/20 이상이며 중대한 오류가 없어야 승격 기준을 충족하지만, 이번에는 실험 권장 구성만 갱신한다. 이 소규모 평가로 일반적인 정확도나 운영 신뢰성을 입증하지 않는다.

## 비교 결과와 결정

개발 1차 통과는 기준9/12, 범위 보강11/12, strict11/12였지만 두 후보 모두 기준이 통과한 신고 안내 문항의 필수 정보를 빠뜨렸다. 사전 회귀 제외 규칙에 따라 두 후보를 탈락시키고 반복·조합·최종20문항 실행은 생략했다. GPT-6 Luna와 기존 기준 구성은 유지하며 서비스 기본값을 변경하지 않는다.

38/166호출(호환성2+개발36), 보수적 API 추정 비용 $0.528206으로 종료했다. 생성 unittest245개와 전체 Ruff 검사·251개 파일 형식 검사가 통과했다. 독립 AI 판정과 경계 재검토를 수행했으며 사람 검수는 아니다. 평가 자료32개 중 합성26개이고 반복 안정성은 측정하지 않았다.
