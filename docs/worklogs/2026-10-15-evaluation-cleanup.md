`generation_evaluation.experiment_support`는 기존 JSON digest와 파일 해시 목록 생성을 담당한다. UTF-8, 정렬된 키, JSON 구분자, 상대경로 키, 누락 파일의 None을 유지한다. manifest에 새 지원 모듈과 이동한 전략을 포함한다. 코드가 바뀐 이전 결과는 provider 생성 전에 resume를 거부하며 manifest를 덮어쓰지 않는다.
