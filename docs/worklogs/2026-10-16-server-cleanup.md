# 서버 잔여 코드 정리와 문서 동기화 통합

## 사용자 결정과 작업 범위

사용자는 미사용 스키마·미채택 실험·구형 trace·중복 조립을 정리하고, 검증 후 문서 동기화 구현과 함께 PR #12를 main에 병합하도록 요청했다. AI가 구현·실행·독립 검토·기록을 수행했다. 사람 검수나 사용자 독립 구현으로 표현하지 않는다.

별도 작업 공간의 최초 기준은 `658d083f3e6cd683981f0945187ebf5fad65e6e0`이며 원격 main은 `c7f428a972e50f3d4ff95784d26583db69888ad5`다. 원래 로컬 main `a23b11a`와 사용자 자료는 보존한다. 진행 중 원격에 게시된 사용자 변경 `edaa0f1` 및 RAG v3 평가·게시 기록 `5e0a39a`도 통합했다. main 병합에는 `[skip ci]`를 적용하며 운영 배포·접속·유료 LLM 호출은 하지 않는다.

## 정리와 유지 경계

| 대상 | 정리 | 보존한 계약 |
|---|---|---|
| 문서 오류 스키마 | 실제 응답·OpenAPI에 연결되지 않은 두 클래스 제거 | HTTP 오류 JSON·상태 코드 |
| 인접 문맥 임베딩 | 미채택 설정과 분할을 retrieval/experiments로 이동 | 기본 청크·spec ID·기존 색인과 묶음, 과거 실험 재현 |
| trace | 과거 실행기 단계 해석을 archive/answering_v1로 분리 | 활성 요청·분류·검색·생성 및 일반 모델 콜백, 환경변수·JSONL·헤더 |
| 의존성 조립 | 두 질문 라우트의 문서·검색·답변 선택 공통화 | snapshot·답변기 선택·routing mode |

worker는 누락·실패 복구와 시행일 도래 문서 반영에 필요하다. full 수동 복구, 기본 벡터 연결, `/regist-docs` 등 공개 호환 API도 유지한다. 서버가 실험·아카이브 코드를 import하는 방향은 허용하지 않는다.

## 검증

동작 보존 작업이므로 기존 결과를 먼저 확보하고 전후 동등성과 기존 회귀 테스트를 확인했다. 구형 체인 이름을 해석하지 않아야 하는 활성 trace 계약은 새 집중 검사에서 변경 전 실패를 확인한 뒤 수정했다.

- 변경 전후 OpenAPI 전체 동일; URL·operation ID·요청/응답 스키마 유지.
- API 관련 25개 검사 통과.
- 웹 124개·타입 검사·전체 ESLint·정적 빌드 통과.

- 정리 직후 전체 Python899개(65.260초), 최신 원격의 v3 실험까지 통합 후 **928개, 63.214초** 통과. 문서 동기화·재시도·잠금·취소·삭제·복원 회귀 검사 포함.
- Ruff check·format check **544파일**, diff whitespace 검사 통과.
- 충돌 해결 문서를 포함한 안내 문서 6개의 상대 링크92개·앵커15개 확인. Mermaid·화면 변경 없음; 별도 시각 렌더링 검사는 하지 않음.
- 분할 회귀 fixture 4개 × 기본/실험 구성의 전체 직렬화 출력72,216바이트 동일. SHA-256 `19361b561ce652f087a4622c6d8a3cb9ac31647e2cbd7f8bad5210e727947752`, 기존 기본·실험 spec ID 유지.
- 독립 읽기 전용 검토자가 관련45개 검사를 통과시켰고, 실제 Tiny tokenizer로 긴 제목·절 제목·본문·표를 조합한45개 문서의 기본/실험90개 전후 비교에서 모든 Chunk 필드 또는 실패 결과의 동등성을 확인했다. 실험 spec 속성과 직렬화의 불일치 지적은 반영했으며 남은 중대한 지적 없음.
- [실제 Tiny 재검증](../../retrieval/reports/2026-10-16-document-sync/evidence/cleanup-tiny-smoke.json)의10개 검사 통과. 초안 임베딩0회, 동일 키 게시 복구35.51ms, 재게시28.65ms, 기본71개 복원77.31ms·문서 임베딩0회. 임시 기본 묶음 준비는298벡터·43.75초로 별도이며, 복원 추론0회와 혼동하지 않는다. WSL2 CPU24 개발환경에서 전체 테스트와 동시 실행한 값으로 운영 지연이나 이전 실행 대비 성능 향상을 뜻하지 않는다.
- 서버·검색 import 검사에서 archive·retrieval.experiments 비참조 확인. 활성 RetrievalService와 검색 C 선택 정책은 변경하지 않았다.

기존 Tiny 증거는 덮어쓰지 않고 후속 JSON으로 보존했다. 이후 main 통합은 활성 동작 변경 없이 사용자 공백 수정과 별도 평가 코드·보고서·문서만 추가했다. 독립 검토자가 v3 원자료·실험 코드가 상대 커밋과 동일함을 확인하고 새 실험29개 검사를 통과시켰다. 문서 충돌은 v3 결과·링크를 유지하고 이전 비동기 복원 설명만 새 계약으로 대체했다. 지적된 EOF 추가 빈 줄은 제거했고 통합 diff 검사도 통과했다. 변경 후보22파일 credential 패턴 검사에서 일치 없음; 전체 이력 검사를 뜻하지 않는다. 상세 실행 로그는 작업 공간의 `tmp/server-cleanup-20261016/`에 있으며 공개 다운로드 자료가 아니다.

실제 운영 배포·2vCPU 운영 성능·사람 검수·LLM 답변 품질은 이번 검증에 포함하지 않는다.
