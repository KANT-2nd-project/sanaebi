- 기존 질문 서비스·라우팅 모드·RAG 서비스/HTTP·advisory 회귀 41개 통과. 원래 checkout의 `.venv/bin/python`을 별도 작업 트리에서 사용했다. 실제 모델 호출이나 운영 DB 쓰기는 없다.
- 변경한 안내 6개 문서의 상대 링크·앵커 141개 확인, 오류 0개. 들어오는 옛 목표 흐름 앵커 참조도 검색했다.
- Mermaid 3개를 임시 Mermaid 11·Playwright Chromium에서 렌더링해 SVG 3개·오류 노드 0개 확인. 전체 페이지 캡처로 글자·분기 표시 확인. favicon 404는 그림 렌더링과 무관하다. 프로젝트 의존성은 변경하지 않았다.
- `git diff --check` 통과. shadow/gate × full/rag, 빈 문서, 알려진 분류 장애, 미준비 색인, assistant 입력 라벨과 생성 인자의 차이를 코드 및 기존 테스트와 대조했다.
