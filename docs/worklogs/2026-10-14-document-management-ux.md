## 게시 전 추가 검증과 남은 환경 조건

후속 사용자 요청으로 이번 UI/UX 코드·문서의 선별 커밋·푸시와 Notion·개인 일지 갱신을 진행한다. 앞선 ‘커밋 미수행’ 기록은 해당 단계의 이력이다.

모바일 접근성 트리에서 열 제목이 빠지는 문제를 추가로 발견해, 모바일 thead를 display:none 대신 시각적으로만 숨겼다. Chromium 접근성 트리에서 4개 열 제목, 두 필수 입력의 required=true를 확인했다. 1440·768·390·320px에서 목록 가로 넘침이 없었다. 실제 스크린리더 낭독 결과는 아니다.

실제 /ask의 ‘연차는 어떻게 신청하나요?’는 분류 모델 부재로 HTTP503이었다. 설치된 qwen3:4b-instruct-2507-q4_K_M을 사용해 현재 71건 SQLite snapshot으로 독립 호출했지만 입력66,652토큰이 설정40,960을 초과해 HTTP400으로 실패했다. 실제 모델 호출은 수행했으나 답변 생성 성공·품질은 평가할 수 없었다. 본문 절단·모델 다운로드·유료 호출·모델 설정 교체는 하지 않았다.

실제 Android 연결 도구와 실행 중인 스크린리더를 찾지 못했다. 사용 가능한 실제 기기를 요청했으며 제공 전까지 모바일 소프트 키보드·스크린리더 낭독은 미검증이다. Headless와 headed Chromium에서 확대 단축키를 시도했으나 DPR·viewport가 바뀌지 않아 네이티브 확대 성공으로 판정하지 않았다. 기존 CSS200% reflow와 320px 검사는 대체 검사로만 기록한다.
