# RAG 가독성 v6·v7 비교 — 2026-10-16

## 결정과 기여

사용자가 승인한 8문항 × 3후보 비교를 AI가 구현·실행하고, 별도 AI가 후보명을 가린 응답을 판정했다. 총 24회 생성으로 실험을 종료했다. 사람 검수나 사용자의 독립 구현 실습으로 기록하지 않는다.

**v6·v7 모두 사전 채택 조건에 미달하여 현재 RAG 기본값 `examples_answer_scope_v5_rag_service_v1`을 유지한다.** v7은 내용 통과 7/8로 가장 좋고 도움 소개가 소개·대표 업무 불릿·실행 한계로 나뉘었다. 그러나 사고 질문의 후속 인계 안내가 빠졌고, 공통 가독성 점수 개선도 요구된 2문항에 미달했다. v6은 출장 증빙 확인 안내에 퇴행이 있었다. 기준점 역시 내용 누락이 있어 기본값 유지는 품질 승인이 아니다.

## 구현

- `generation/rag_readability.py`: 현재 RAG 프로필에 보관된 v6/v7_readability의 추가 문구를 정확히 붙인 두 실험 후보를 등록했다. 기존 프로필 본문은 유지했다.
- `generation/profiles.py`, `generation/service.py`, `app/answering/adapter.py`, `app/settings.py`: 빈 근거 지원과 프로필 선택을 명시적인 RAG 지원 집합으로 연결했다. 접두사 추정은 하지 않는다.
- `generation_evaluation/rag_readability.py`: 고정 입력·루브릭·가격·코드·실제 프롬프트 해시, 원응답 즉시 저장, 원자적 호출 예약, 24회 상한, 중단·재개 및 변경 탐지를 구현했다.
- 테스트는 프로필 동일성·후보 차이·JSON 개행·빈 근거·파싱 실패와 호출 상한·재개·변경 차단을 포함한다.

## 검증과 실행 기록

전체 Python 테스트 1075개와 Ruff 검사·형식 검사(최종 재검사 619파일)를 통과했다. 실제 생성 24개 모두 JSON/API 정상 완료했다. 합계 입력 179482토큰·출력 14743토큰, 보수적 가격 추정 $0.05592775다. 실제 청구 금액은 아니다. 완료 후 재개 명령으로 24개 모두 건너뛰고 추가 호출 0회를 확인했다.

저장 답변을 현재 `/chat` Markdown 표시 경로에 주입해 1280px/360px의 48개 화면 상태를 확인했다. 가로 넘침과 페이지 오류는 없었다. 스크린샷·계측 두 실행의 브라우저 mock 응답은 총96회이며 추가 모델 호출은 없었다. 웹 코드는 수정하지 않았다. 실기기·스크린리더 검증은 아니다.

중단 전 체크포인트를 보존한 뒤 재개했다. 판정 경계는 원문과 사전 루브릭으로 재검토하고 초기 판정도 보존했다. 상세 문항별 판정·채택 조건·근거·응답·시간·가격은 [실험 보고서](../../generation_evaluation/reports/2026-10-16-rag-readability/README.md)를 기준으로 한다. 실험 자료는 저장소 내부에 있으나 Git ignore 대상이므로 Git 백업과 구분한다.

## 적용 범위와 보존

로컬 RAG 기본값 변경 없음. 독립 CLI/full은 v5 유지. 실험 준비 시 프로필 환경변수 재정의는 없었으며 `freeze.json`에 기록했다. 서버 수동 재시작·배포·커밋·푸시·Notion 게시를 하지 않았다. 기존 개발 서버의 자동 reload 가능성과 수동 재시작은 구분한다. 기존 프로필 정리 변경과 사용자 발표 자료를 보존했다.

각 문항 1회이며 일반 품질이나 반복 안정성의 증거로 확대하지 않는다. 다음 작업을 한다면 가독성 추가보다 사고 대응 필수 인계·기록 안내 누락을 별도 개선 대상으로 삼는다. 이번 승인 범위에서는 추가 튜닝·생성을 하지 않았다.

후속 사용자 선택과 배포는 [별도 채택 기록](2026-10-16-rag-v7-adoption.md)을 따른다. 이 문서의 실험 보류 판정은 변경하지 않았다.
