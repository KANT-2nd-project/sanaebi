# 생성 모델 강화·20문항 선정 실험 — 2026-10-15

## 목적과 역할

Qwen3 4B Q4_K_M과 GPT-6 Luna의 근거·조건·권한 오류를 줄이고 다음 개발에 사용할 구성을 선정한다. 사용자가 이번 구현·실험·AI 검토·게시를 명시적으로 위임했다. 사용자가 앞서 직접 작성한 생성 모듈과 이번 AI 구현을 구분하며, 사람 품질 승인이나 독립 학습 숙련도 검증으로 기록하지 않는다.

## 사전 고정과 실행 경계

- 71문서 snapshot, 개발 8문항, 별도 질문 그룹 최종 20문항, 8개 차원별 rubric을 응답 검토 전에 고정했다. 최종 문항을 작성한 독립 검토자는 실험 응답을 열지 않았고 프롬프트 작성자는 튜닝 중 최종 문항을 읽지 않았다.
- 최종 20문항은 정상8·자료 부족4·조건/예외4·조회/실행2·잘못된 전제2로 구성했다. 기존 SEARCH_KNOWLEDGE18개와 합성2개다. 정확한 근거 인용75개와 그룹 비중복을 검증했다.
- 형식뿐 아니라 문서 근거, 적용 범위/조건, 필수 안내, 유보, 실행 한계, 말투, 관련성을 판정한다. 금지된 행동을 하지 않았으면 충족으로 보며 질문에 무관한 정책까지 명시적으로 부정하도록 요구하지 않는다.
- 독립 worktree에서 기존 생성 브랜치와 최신 origin/main을 대조·병합했다. 원본 작업 트리의 별도 서버 변경·데이터·스테이징은 건드리지 않았다. main으로 병합하지 않는다.
- 별도 Ollama11435, FA/q4_0 KV/parallel1/fit256, context98304, output1024, temperature0, seed42. GPU37/37층·KV3888MiB 적용을 실제 로그에서 확인했다. GPT는 output1024/none/temperature0, 자동 재시도0으로 시작했다.
- 첫 요청 예약부터 개발70분/$3, 전체120분/$5 제한을 공유한다. 최종에 최소50분/$2를 남기고 남는 개발 예산도 넘긴다. 비용은 긴 문맥 단가의 보수적 사용량 추정이며 청구서 실액이 아니다.

실행 원자료는 `tmp/generation-selection-20261015/`에 보존한다. 코드·문항·문서·프롬프트 hash, 단계별 응답/사용량/실효 설정, 시작 이벤트·완료 기록을 분리한다. 완료 항목의 재개는 호출하지 않고, 결과가 불확실한 중단은 수동 조정 없이 재호출하지 않는다. 근거 추출 검증 실패를 숨겨 재시도하거나 단일 생성으로 대체하지 않는다.

## 사용자 요청으로 일시 중단

진행 중이던 Qwen 최선 후보 두 번째8문항 실행까지 완료하고 중단했다. 개발 응답 총88건·내부 모델 호출92회이며 최종20문항 비교는 시작하지 않았다. 개발 판정80건을 저장했고 마지막 Qwen 반복8건의 독립 판정은 재개 후 진행한다. API 예산 정산의 보수적 추정은 0.479406달러이며 미정산 예약은 없다.

GPT의 개발 기준점은 통과4/실패2/불확실2, 대조 예시1회는 통과6/실패1/불확실1이었다. low는 조회 권한 오류가 되돌아와 제외했고 근거 추출은 통과4/부분3/실패1로 완전성이 나빠져 제외했다. 단일 대조 예시2회째는 통과4/부분2/불확실2로 반복 변동이 남았다.

Qwen은 기준점 통과3/실패4/불확실1, 대조 예시1회 통과4/실패3/불확실1이었다. 근거 추출은 정상 문항까지 파싱·원문 검증 실패하여 통과1/부분2/실패5로 제외했다. 같은 고정 유보문을 두 모델에서 다르게 판정한 경계는 동일 기준으로 부분 충족에 맞췄다.

전용11435 모델·서버를 종료했다. 체크포인트와 원자료는 원본 저장소의 `tmp/generation-selection-20261015/`에도 보존한다. 재개 시 사용한 비용·활성 시간을 이월하고 완료 응답을 재호출하지 않는다. 최종 선정·기본값 승격·Notion 반영·이번 로컬 커밋 푸시는 미완료다.
