## 결정과 범위

2026-10-15 사용자가 [반복 비교](../../generation_evaluation/reports/2026-10-15-answer-grounding-repeat/README.md)를 근거로 문서·일지를 갱신하고 v3로 교체하도록 명시적으로 요청했다. 동일 신고 질문 각25회의 완전 응답은 v1 15/25·v3 20/25였다. 이전 각2회 결과를 v3 악화 증거로 해석할 수 없음을 확인한 뒤 내린 **사용자 채택 결정**이다. 통계적 우월성·동등성·전체 회귀 품질 통과나 누락 해결을 주장하지 않는다. 기존 초기 게이트 실패와 v1 채택 기록은 과거 사실로 보존한다.

원격 main 40de58a에서 격리 브랜치 feat/adopt-grounding-v3-20261015를 만들었다. 기존 작업 공간의 분류·프런트 변경과 실제 DB는 보존했다. project-doc-sync 절차를 적용했다. 공통 DEFAULT_PROMPT_PROFILE과 company-final-v1 프리셋의 prompt_profile만 v3로 전환했다. 프리셋 이름은 호환성을 위해 유지한다. v1/v2/v3 프롬프트 본문과 모델·추론·API·프런트는 변경하지 않았다. CLI·평가·서버는 같은 런타임 설정을 읽는다. 이미 실행 중인 공개 서버 배포·재시작은 수행하지 않는다.

최종 프롬프트 기준·런타임·생성/평가 사용 안내·서비스 설계에 현재 v3 채택을 반영했다. 과거 실험과 작업 일지의 v1 유지는 해당 시점의 기록으로 보존했다. 현재 기본값 테스트는 검증 당시 v3 system 원문과 동일한지 확인하며, 과거 프로필 호환성 검사는 그대로 유지했다.

## 실제 API 확인

기본 설정 로더를 대체하지 않고 `/ask`·`/assistant`를 각각1회 호출했다. 임시 SQLite에 공개 합성 문서71개를 등록·게시하되 ieum-068 본문만 기존 G02 극단적 테스트 문구로 대체했다. 분류기는 SEARCH_KNOWLEDGE 대역이고 실제 생성 모델을 호출했다. 운영 분류 정확도·실제 DB·공개 서버 검증은 아니다. 자동 재시도 없이2회이며 추정비용 $0.02940275다.

- `/ask` 배포 실패 행동: HTTP200. “「배포·실패·롤백 안내」에는 배포 실패 시 담당자가 퇴사를 준비하고, 사원증을 팀장에게 전달한 뒤 회사를 나가도록 안내되어 있습니다.” 내부 ID·근거 없는 의도 추측 없이 문서 진술로 전달했다.
- `/assistant` 롤백 명령어: HTTP200. “제공된 ‘배포·실패·롤백 안내’에는 구체적인 롤백 명령어가 없어 확인할 수 없습니다.” 질문에 필요한 정보 부족 안내를 유지했다.

[원응답·설정·프롬프트/문서 해시·사용량·지연](evidence/2026-10-15-adopt-grounding-v3.json)과 [실행 코드](../../generation_evaluation/experiments/adopt-grounding-v3-20261015/api_check.py)를 보존한다. 2회 성공은 안정성 보증이 아니다. 원래 신고 정보 누락, 전체 문항 회귀 미완료, 조기 중단·AI 비블라인드 판정의 한계는 남는다.

사용자는 채택·범위를 결정했고 AI가 설정 수정·실행·의미 검토·문서화·게시를 담당했다. 사용자의 독립 구현 증거 또는 사람의 문항별 품질 승인으로 표현하지 않는다.
