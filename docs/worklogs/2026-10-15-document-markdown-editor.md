# 문서 Markdown 읽기·확장 편집과 채팅 입력 정렬

## 문제와 결정

문서 본문의 Markdown이 일반 텍스트로 보이고, 좁은 본문 분할과 별도 제목 입력으로 편집·미리보기를 함께 보기 어려웠다. 사용자가 Markdown 읽기, 제목 포함 분할 편집, 화면 확장과 라이브러리 도입·게시를 결정했다. AI가 공식 자료 조사·구현·모의 브라우저 검증·문서화를 수행했다. 사용자 독립 구현이나 사람 검수 완료를 뜻하지 않는다.

## 구현

- 채팅 성공 답변·문서 읽기·충돌 초안·미리보기는 공통 MarkdownContent를 사용한다. HTML 무시·이미지 대체 텍스트·절대 HTTP/HTTPS 링크 정책과 원문 저장을 유지한다.
- 작성·편집만 최대 1600px, 목록·읽기는 1120px다. 1024px 이상은 제목·원문과 미리보기 두 열, 좁은 화면은 탭이다. 높이는 화면에 맞춰 늘고 낮은 화면은 페이지 스크롤을 허용한다. 본문 최소 320px, 미리보기 읽기 폭 최대 720px와 독립 스크롤·하단 저장 접근성을 제공한다.
- @uiw/react-md-editor 4.1.2의 nohighlight 편집 전용 모드와 기존 렌더러를 결합했다. 8종 사용자 정의 서식, Ctrl/Cmd+B·I·K, 목록 이어쓰기, 기본 Tab 이동, 실행 취소/다시 실행을 제공한다. 한글 조합 중 명령 처리와 50,000자 초과 편집을 막는다.
- 제목과 본문은 별도 원문 필드로 저장한다. 저장·게시 분리, 충돌 처리·미저장 입력 보호·저장 중 비활성화를 유지한다.
- 앞선 사용자 요청인 채팅 전송 버튼 최소 높이 36px와 안내 문구의 같은 행 하단 정렬을 별도 기능으로 게시한다.

## 라이브러리 선택 근거

[uiw 공식 README](https://github.com/uiwjs/react-md-editor)는 textarea 기반 편집·명령 사용자화·Next.js 사용법을 제공한다. 기존 Markdown 문자열 계약에 맞고 직접 만든 선택/서식 규칙을 사용자 정의 명령으로 연결할 수 있다. 내장 미리보기·이미지·전체 화면·드래그 높이는 쓰지 않는다. 미리보기 정책은 기존 렌더러에 한정한다.

[CodeMirror Markdown](https://github.com/codemirror/lang-markdown)은 향후 편집 기능 확장 후보이며 툴바·화면 조립이 추가로 필요하다. [TOAST UI](https://ui.toast.com/tui-editor/)와 [MDXEditor](https://mdxeditor.dev/editor/docs/diff-source)는 서식 편집 기능까지 필요한 경우의 대안이다. 이번에는 원문 중심 편집을 유지했다.

## 검증

- 웹 단위 테스트 80개, lint·typecheck·정적 build 통과.
- 문서 브라우저 61개: 게시/초안 읽기, 제목 일반 텍스트, 서식·선택·undo/redo·단축키·목록 이어쓰기·Tab, 반응형·원문 저장·503·409·저장 중 비활성화 확인. 쓰기 3회는 모두 모의 API다.
- 경계 브라우저 32개: 합성 IME 이벤트, 연속 undo/redo, 초과 붙여넣기·목록 이어쓰기 차단, 제목 오류 포커스, 긴 표/코드 키보드 스크롤, 낮은 화면·저장 접근성·1600px/720px 제한 확인.
- 채팅 회귀 45개: Markdown·링크·HTML/이미지 차단·누적 대화·오류/재시도·사용 안내·가로 스크롤 확인. 실제 외부 이미지 요청 0건.
- 320·390·768·1023·1024·1440·1920px 및 480/600px 높이 검사. 최종 CSS에서 충돌 본문 높이 제한을 재확인했다.
- 로컬 캡처·재실행 스크립트·로그: `tmp/document-markdown-editor-2026-10-15/`의 `library-*`. 원자료는 Git에 포함하지 않는다.

50,000자 미리보기는 로컬 단일 모의 본문으로 확인한 것이며 보편적인 성능 보장은 아니다. 실제 기기·가상 키보드·스크린리더·다른 브라우저의 네이티브 편집 이력은 미검증이다. 실제 문서 쓰기·LLM 호출·서버 API 변경은 하지 않았다. npm audit high 5건은 기존 ESLint 경로이며 이번 편집기 경로에서 추가된 항목은 없었다. 강제 업그레이드는 하지 않았다.

## 게시와 기록

이번 웹·문서 변경만 기능별로 분리한다. 병행 생성 코드·결과·커밋과 데이터·가중치·실제 환경 파일은 포함하지 않는다. 원격 게시 뒤 관련 Notion 요약과 새 개인 일지를 갱신하고 재조회한다. 게시와 실제 서비스 배포·실모델 응답 검증은 구분한다.
