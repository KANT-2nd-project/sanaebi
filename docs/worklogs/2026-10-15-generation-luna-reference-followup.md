# 2026-10-15 GPT-6 Luna 답변 범위·출력 계약 후속 실험

## 목적과 범위

선택 모델은 GPT-6 Luna로 유지한다. 기존 `examples` 프롬프트의 부분 답변·필수 안내와 JSON 출력을 개선할 수 있는지 별도 실험으로 확인한다. 기준 커밋은 생성 브랜치 `97af57b`이며 기존 중단 실험의 미커밋 결과를 보존했다. 새 실행은 `luna-reference-followup-v1` 원장·폴더를 사용한다.

사용자가 승인한 최대 생성 호출 수는 166회다. 금액·전체 시간 상한은 없으며 호출별 timeout 180초, 비용 추정과 실패 기록은 유지한다. 서버 연결·검색·모델 교체·학습·자동 재시도·2단계 실험은 수행하지 않는다.

## 구현 중 확인한 문제와 조치

- 신규 프로필은 조사 자료의 최소 추가 문단만 사용하고, 기존 6개 프로필은 해시로 동일성을 검증했다.
- strict JSON Schema를 전달할 때 설치된 SDK의 자동 parse 경로가 잘림 응답의 원문과 사용량을 가릴 수 있었다. 독립 코드 검토에서 확인한 뒤 Chat Completions 원응답 경로로 바꾸고 종료 메타데이터까지 `AIMessage`에 보존했다.
- 명시적 거절을 파싱 오류와 분리했다. 거절을 우선 판단하고, 잘림·추가 키·공백 응답을 각각 기존 계약에 맞게 처리한다.
- 무제한 금액/시간은 신규 원장에서만 명시적으로 선택한다. 최대 166회 호출 예약은 공유 원장 잠금 안에서 수행한다. 사용량 미수신은 무료 호출로 기록하지 않는다.
- 개발 평가 자료의 독립 검토에서 원본 질문 ID 불일치, 인용 범위 부족, 질문 밖 필수 주장을 발견했다. 생성 실행 전에 수정했으며 이를 모델 실패로 취급하지 않았다.

## 검증·실행 기록

구현 후 생성 unittest 242개, 저장소 전체 Ruff 검사·형식 검사가 통과했다. 평가 자료 검증 추가 후 생성 unittest 245개, 전체 Ruff 검사 및 251개 파일 형식 검사가 다시 통과했다. strict 실호출 2건은 정상 JSON 및 이스케이프 문자열 보존을 확인했다. 이 2건은 답변 품질 점수에 포함하지 않지만 호출 한도에는 포함한다.

신규 평가 자료는 독립 AI 검토 `PASS_WITH_LIMITATIONS`로 고정했다. 개발 1차36응답 모두 정상 완료했고 후보명을 가린 독립 AI 판정과 경계 재검토를 마쳤다. 자료32개 중 기존 라우팅 질문6개·합성26개이므로 일반 운영 질문 분포를 대표하지 않는다. 기준9/12, scope11/12, strict11/12 통과였지만 두 후보 모두 DEV-FU-09 필수 신고 정보에서 회귀했다. 사전 제외 규칙을 적용해 두 후보를 탈락시키고 반복·조합·holdout 실행은 생략했다. 모델과 기존 기준 구성을 유지한다.

## 기여와 학습 기록 구분

이번 코드 구현·테스트 실행·모델 호출·자료 작성·독립 판정은 AI가 수행했다. 사용자는 실험 방향, 평가 항목, 실행 한도와 게시 범위를 결정했다. 이를 사용자의 독립 구현·검수 역량 증거로 기록하지 않는다. 독립 판정자는 별도 AI이며 사람 승인이나 운영 품질 검수로 표현하지 않는다.

## 결정에서 배운 점

총 통과 수 개선만으로 채택하면 특정 필수 업무 정보의 회귀를 감출 수 있다. 이번 게이트는 비중대 누락도 명확한 필수 안내 회귀이면 제외하도록 정했으므로 결과 후 완화하지 않았다. JSON Schema는 출력 구조를 제한하지만 내용 누락을 해결하지 못했고, 이번 형식 오류는 세 후보 모두0건이었다.

평가자도 오류를 낼 수 있었다. DEV-FU-09에서 대체 문의 경로 두 개를 모두 요구한 판정 이유를 고정 기준에 맞게 정정했다. 최종 partial은 다른 필수 정보 누락 때문에 유지했다. DEV-FU-10의 필수 주장은 질문 해결에 필요한 범위보다 넓을 수 있으므로 그 개선의 실용적 의미를 제한해서 기록했다. 기준은 사후 변경하지 않았으며 다음 실험에서 새 버전으로 검토할 사항이다.
