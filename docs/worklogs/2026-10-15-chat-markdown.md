# 채팅 답변 Markdown 표시 — 2026-10-15

## 결정과 구현

사용자는 별표가 그대로 보이는 답변을 Markdown으로 표시하도록 결정하고 구현·검증·게시를 위임했다. AI가 공식 자료 검토, 컴포넌트·스타일·문서 작성과 검증을 수행했다.

성공 답변만 AnswerMarkdown으로 표시한다. react-markdown10.1.0·remark-gfm4.0.1·remark-breaks4.0.0을 추가했다. 강조·h3 이하 제목·문단·줄바꿈·목록·인용·코드·표·취소선·읽기 전용 체크 목록을 지원한다. 표·코드 블록은 키보드로 내부 가로 스크롤할 수 있다. 사용자 질문·오류·대기는 일반 텍스트를 유지한다.

HTML은 무시하고 이미지 대신 alt를 표시한다. 절대 HTTP/HTTPS 링크만 새 탭으로 열며 noopener noreferrer와 접근성 안내를 제공한다. 다른 링크는 텍스트로 남긴다. 서버 응답과 저장 문자열·모델·API는 변경하지 않는다.

현재 사용 기준은 [웹 안내](../../web/README.md#질문-요청과-테스트)와 [프런트엔드 설계](../frontend-architecture.md#요청-흐름과-계약)에서 관리한다.
