## 검증

- 변경 대상 안내 문서 8개의 로컬 링크·앵커 147개 확인: 누락 0. 작업 기록을 포함한 게시 대상 9개 문서의 링크·앵커도 Git index 기준으로 147개 확인했다. 기존 미게시 변경의 새 링크는 커밋에 포함하지 않았다.
- 다섯 독자 시나리오: 신규 팀원의 준비·실행·확인, 서버 학습자의 루트→서버→추론, 교체 담당자의 추론→설정·재시작, 실험 담당자의 학습→보고서·서버 설명, 문서 관리자의 루트→관리 절차를 확인했다.
- MarkdownIt로 로컬 preview를 만들고 Chromium·Mermaid 11.12.0에서 신규 4개 그림과 기존 서비스 그림 1개를 렌더링했다. 신규 그림 4개의 캡처를 시각 확인했으며 텍스트·화살표·표가 표시됐다. 로컬 preview는 GitHub와 동일한 렌더러라는 뜻이 아니다.
- 실제 선정 모델 `9f51682d82d4455d8296077c339afd58`로 TestClient HTTP 검사를 수행했다. `GET /` 200, 분류 요청 200, 공백 입력 422. 임시 SQLite를 사용했으며 답변 실행기를 호출 시 실패하도록 대체해 LLM 호출 0회를 확인했다.
- 단건 질문 “출장비 정산 절차 알려줘”의 예측은 `UNSUPPORTED`였다. 올바른 정답 판정이나 신규 성능 평가가 아닌 관측 결과로 남긴다. 질문 해석·라벨 경계 검토는 별도 과제이며 이번에 모델·데이터를 수정하지 않았다.
- 명령은 package.json·설정·요청 스키마와 대조했다. npm 통합 개발 서버·실제 curl·실제 LLM 종단은 이번에 다시 실행하지 않았다. HTTP 확인은 TestClient로 수행했다.
- 문서만 변경하므로 전체 Python·모델 테스트는 재실행하지 않았다. `git diff --check`를 확인했다.

검사 스크립트·preview·캡처·단건 로그는 로컬 `tmp/readme-implementation-2026-10-15/`에 둔다. Git에는 이 요약만 남기며 로컬 자료를 공개 다운로드 링크처럼 제공하지 않는다. 조사 보고서는 로컬 `tmp/readme-architecture-review-2026-10-15/report.md`에 보존한다.
