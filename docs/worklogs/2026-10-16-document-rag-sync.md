# 문서 변경의 RAG 즉시 반영과 응답 완료 보장

## 요청과 범위

사용자는 시연에서 게시 성공 직후 검색 가능한 동작을 선택했고, 문서 저장 뒤 색인 실패 시 저장을 보존하고 같은 요청으로 재시도하는 정책을 확정했다. 구현·검증·문서·개인 일지·Notion·기능별 커밋·푸시를 위임했다. AI가 구현·실행·독립 검토·기록을 수행하며 사용자 독립 구현이나 사람 검수로 표현하지 않는다.

기준은 원격 main `c7f428a972e50f3d4ff95784d26583db69888ad5`다. 별도 작업 공간과 기능 브랜치를 사용하며 원래 로컬 main의 미통합 커밋, 기존 가중치·DB·실험 자료를 보존한다. main 병합·운영 접속·배포·유료 LLM 호출은 범위 밖이다.

## 변경과 판단

- 초안은 기존대로 저장한다. 게시·철회·전체 삭제·기본 복원만 현재 검색 준비 확인까지 기다린다.
- 문서와 색인 DB를 하나의 트랜잭션으로 취급하지 않는다. 저장 후 실패는 503과 저장 여부를 표시하고 동일 멱등 요청으로 복구한다.
- API·worker·복원이 작업 단위 잠금을 공유한다. worker는 누락·실패·시행일 도래의 복구 역할을 유지한다.
- 기본 복원은 설정된 host 원본과 묶음을 사전 확인한 뒤 모델 추론 없이 연결한다. full 호환과 현재 C 검색 설정은 유지한다.
- 웹은 요청 완료까지 기다리고 부분 실패에 같은 요청 본문·키를 보존한다.

현재 계약은 [문서 관리](../document-management.md#rag-색인과-자정-초기화), 운영 준비는 [RAG 실행](../rag-runtime.md), 실제 모델 실행은 [검증 보고서](../../retrieval/reports/2026-10-16-document-sync/README.md)를 따른다.

[브라우저 판정](../../retrieval/reports/2026-10-16-document-sync/evidence/browser-check.json)은 API를 모의한 검증이며 실제 Tiny HTTP 결과와 구분한다. 화면 캡처7개와 재현 스크립트는 작업 공간 tmp에 보존했으며 공개 다운로드 링크가 아니다.

## 독립 검토

별도 읽기 전용 검토자가 잠금 오류의503 처리, full 모드 자정 reset 환경, API·candidate 기본 묶음 연결, 복원 재시도의 모델 추론0회, CLI의 부분 완료 안내를 지적했다. 모두 반영했고 검토자가 관련78개 검사를 직접 통과시켰으며 남은 중대한 결함을 발견하지 못했다고 보고했다. 검토 당시 기준 HEAD는 c7f428a이고 최종 소스는 아래 기능 커밋으로 연결한다.

로컬 Docker 통합 실행·2vCPU 운영 성능·실제 LLM 답변 품질·사람 검수·운영 배포는 수행하지 않았다. 이번 변경은 문서 반영 완료 경계를 보장하며 검색 품질 향상을 주장하지 않는다.

## 게시·외부 반영

서버·복구 `eeb6e42`, 웹 재시도 `c0c4903`, 문서·검증 `b2bfe4a`로 나누어 기능 브랜치 `feat/document-rag-sync-20261016`에 푸시했다. [PR #12](https://github.com/KANT-2nd-project/sanaebi/pull/12)를 생성했고 원격 HEAD가 게시 커밋과 일치함을 확인했다.

[CI 실행](https://github.com/KANT-2nd-project/sanaebi/actions/runs/38764802581)은 `b2bfe4acf3bc38cf803f01c82e5c6e61cf6dd432`에서 Python·웹·이미지 빌드와 CPU 런타임 검사를 통과했다. deploy job은 건너뛰었다. 이 게시 결과만 추가하는 후속 커밋에는 `[skip ci]`를 적용한다. CI 이미지 검사는 운영 볼륨을 사용한 배포·복구 검증과 구분한다.

Notion의 프로젝트 문서 안내·서비스 처리 기준·운영 개발 규칙에 기능 브랜치의 현재 계약과 게시 링크를 반영하고 재조회했다. [개인 일지](https://www.notion.so/3fa05a3cdadc8193b9c0db7ce394977b)는 중복 없음 확인 후 생성했으며 담당자 최재선·검색/생성 영역·2026-10-16 날짜와 본문·링크를 확인했다. CI 확인 후 해당 일지만 완료로 표시하고 다시 읽었다.

main 병합·운영 접속·배포는 수행하지 않았다. 원래 로컬 main `a23b11a8fdbfbdc2a4a712f22b81b33da6a84d82`와 자료는 보존했다. 이번 작업 공간은 커밋 대상에서 제외한 `.venv` 연결만 남는다.

## 후속: 서버 정리와 main 통합

사용자의 후속 요청으로 서버 잔여 코드 정리와 최신 main 통합·검증을 마친 뒤 [PR #12](https://github.com/KANT-2nd-project/sanaebi/pull/12)를 `eff72266b8043a4a7794ed5646235b71ff5546ab`으로 병합했다. 병합 제목의 `[skip ci]`로 이번 운영 자동 배포를 제외했다. 위 검증 수치와 기능 브랜치 게시 당시 기록은 유지한다. 후속928개 Python 검사·CI·독립 검토·Notion 재조회는 [별도 정리 기록](2026-10-16-server-cleanup.md)을 따른다.
