# KURE 검색 전환 검증과 질문 단위 점수 게이트

사용자는 KURE 상위20과 검증된 질문 게이트를 함께 적용하되 사전 조건 실패 시 Tiny C를 유지하도록 결정했다. AI가 자료 작성·구현·실제 로컬 검색·독립 AI 검토·문서 정리를 수행했다. 사용자 독립 구현이나 사람 검수로 기록하지 않는다.

## 결과와 범위

[정식 보고서](../../retrieval/reports/2026-10-16-kure-gate/README.md)가 수치·판단의 기준이다. 개발68을 실행해 하한0.42882221937179565를 동결했고 신규40을 한 번 비교했다. 필수 근거 유지와 자원 기준은 통과했지만 무관 질문 차단4/10으로 최소5/10에 미달해 **전환 보류·Tiny C 유지**다. 확인 결과로 하한을 다시 조정하지 않았다.

과거 pilot 원자료·코드·출처를 먼저 보존하고 평가 실행기·게이트/채택 규칙·집중 테스트·동결 질문·결과·검토를 추가했다. 기존 정책군 중복, 동등 근거·조건 범위, canonical 관련성 강제와 벡터 행 순서 검증 문제를 발견하고 수정했다. 초안·폐기안과 수정 경위를 보존했다.

이번 조건부 서버 전환은 진행하지 않았다. KURE index·기본 복원 묶음·release descriptor를 새로 만들지 않았고 app·서버 설정·생성 설정·분류 정책·Tiny/full 복구를 변경하지 않았다. 기존 DB·원본 문서·가중치·과거 벡터는 보존했다. 원본 DB·색인은 임시 복사본을 읽고 SHA로 전후 확인했다.
