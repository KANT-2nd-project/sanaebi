# 답변 가독성 지침 구현·16회 비교·채택 보류

사용자는 ‘너는 뭘 도와줄 수 있어?’에 대한 답변이 한 문단에 밀집해 읽기 어렵다고 보고했다. 공식 가이드 조사 후 지침 반영, 가벼운 독립 검증, 문서·Notion 일지와 main 커밋·푸시를 요청했고 실제 비교는 16회로 결정했다.

## 구현과 실험

기준 main은 `389e936`이며 기존 웹·문서 편집 작업은 보존했다. AI가 기존 v5에 문단·목록 선택과 JSON 개행 지침, 실제 평가 답을 사용하지 않은 합성 서식 예시를 추가한 v6를 구현했다. v5의 저장 프롬프트 본문은 테스트로 동일성을 확인했다.

공개 Intercom·Microsoft·Anthropic 지침과 GOV.UK·Google 설계 자료를 참고했다. 비공개 상용 시스템 프롬프트를 확보하거나 그대로 재현한 것은 아니다. [조사와 한계](../../generation_evaluation/reports/2026-10-15-readability-v6/research.md)를 보존했다.

별도 AI가 호출 전에 지침 충돌과 사전 루브릭을 검토했다. 실제 시도 수가0으로 고정되는 manifest 필드를 제거하고 누락된 원문 인용2개를 보완한 뒤 동결했다. 당시 SQLite 게시 문서72개의 snapshot은 읽기 전용으로 한 번 가져왔고 DB/WAL 해시가 캡처 전후 같았다.

8문항 × v5/v6 각1회, **총16회**를 순차 실행했다. 자동 재시도·fallback·추가 튜닝·추가 실호출은 없다. 모두 정상JSON 완료이며 프롬프트 해시가 사전 manifest와 일치한다. 보수적 Standard 요율 비용 추정 합계는 **$0.23940425**다. 이는 청구액이 아니다.

## 판정과 결정

후보 이름·실행 순서를 가린 새 AI 검토자가 판정했다. 서식으로 후보를 추측할 가능성을 완전히 제거할 수는 없고 사람 검수도 아니다. 내용은 양쪽7통과/1실패, 가독성은 v5 8통과와 v6 5통과/3부분이다.

- 도움 소개는 v6에서 문단2개가 됐지만 대표 업무가 긴 문장에 나열되어 불릿목록 조건 미충족.
- 출장 조건 분기와 부분 답변은 훑어보기 개선이 있었지만, 순차 절차에서는 조건부 대체 구매와 사후 기록이 한 단계에 섞였다.
- 사고 대응은 두 후보 모두 당직·대체 인계 안내가 빠졌다. v6에는 v5의 발견 시각·실제 회수 확인 안내도 빠졌다.
- 검토자는 처음 ‘보안 > 사고 신고’를 발명된 메뉴로 판단했다. 부모 AI가 전체snapshot ieum-069·071의 실제 명칭을 제시했고 검토자가 재조회해 이 판정을 철회했다. 최초판정·정정판정을 분리 보존한다. 명시적 중대 허구 오류0건이어도 필수 안전 안내 누락은 내용실패다.

**기본값은 v5 유지. v6는 미채택 후보로만 보존한다.** 채택 기준 미달이면 유지한다는 승인된 계획에 따른 결정이며, 결과를 본 뒤 유리한 답이 나올 때까지 재실행하지 않았다. 이전 실험과 이번 점수를 합산하지 않는다.

- 생성 unittest117개, runtime unittest210개 통과.
- 전체 Ruff check·format check 통과(385 Python 파일).
- 실행기 mock으로16슬롯, 교차순서, 주입오류 보존, 사용량 누락시 예약비용, 동일 출력 경로 차단을 확인했다.
- 부모가 원응답16개를 별도로 파싱해 answer 단일키·문자열 일치를 확인했다.
- Playwright의 로컬 채팅 API 응답을 저장된 결과로 대체했다. 1280px·360px에서16응답을 재생한 최종32측정 모두 가로넘침0. 문단·불릿·번호 표시를 확인했다. 측정 로그 수집을 위한 재생까지 mock 응답64회, 추가 backend/model 호출0회다.
- 초기 브라우저 실행은 Chrome 경로 부재로 실패하여 이미 설치된 Chromium 실행 경로를 명시했다. 이후 화면 검증을 완료했다. 실기기·스크린리더·사람 사용성 검증은 아니다.
- 화면은 진행 중인 웹 리팩터링 작업 트리를 사용했으며 소스 해시와 검증 범위를 보고서에 남겼다. 해당 파일은 이번 변경·커밋에 포함하지 않는다.

## 게시와 기여 구분

이번 조사·구현·mock 및 실모델 실행·독립 AI 검토·기록은 AI가 수행했다. 사용자는 문제 발견과 목표·검증 규모를 결정했다. 사용자 독립 학습·구현 성취나 사람 검수로 대체하지 않는다.

main push를 계기로 공개 배포가 실행될 수 있는 `.github/workflows/delivery.yml`을 확인했다. 이번 요청은 공개 배포를 제외하므로 커밋 메시지에 `[skip ci]`를 넣어 push 워크플로를 건너뛴다. [GitHub 공식 동작](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/skip-workflow-runs)에 따른 것이며 로컬 검증과 원격 CI 실행을 구분한다. 워크플로·운영 환경 설정은 수정하지 않는다. 이후 다른 작업의 push는 별개다.
