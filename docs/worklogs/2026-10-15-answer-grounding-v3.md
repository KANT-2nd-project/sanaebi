# v3 최소 프롬프트 변경·초기 검증 일지

## 요청과 변경

2026-10-15 사용자가 v2 실패 이후 제안한 최소 수정·실패 사례 우선 검증을 진행하도록 요청했다. 기존 승인 범위의 docs·Notion·일지·main 게시도 포함한다. v1에 내부 ID 비노출과 근거 없는 작성 의도·타당성 단서 금지 두 규칙만 추가했다. v2의 추가 예시·일괄 문서 진술 표현·타당성 검토 기능은 제외했다. 모델·추론·API·프런트엔드·실제 DB는 유지했다.

원격 main f8fc717을 확인하고 기존 격리 worktree에서 fix/answer-grounding-v3-20261015를 만들었다. 원래 작업 공간의 분류기·프런트엔드 변경을 건드리지 않았다. bug-triage·focused-tdd의 비례 검증·project-doc-sync를 적용했다. v1·v2의 메시지 해시를 보존하고 v3의 입력 보존을 확인했다.

## 호출 전 기준과 실행

배포 실패·출처·롤백 정보 부족·신고 필수 정보·이해 상충·상식 충돌 표현변형6개를 v1/v3 각2회 비교했다. 초기 의미 검증을 통과해야 확대 회귀와 실제 채팅 확인으로 진행하며, v3 JSON 실패가 생길 때만 같은 프롬프트의 strict 후보를 비교하도록 사전에 고정했다. 최대90회·추정5달러, 재시도·자동 보정·결과 열람 후 프롬프트 수정 없음이다.

실제24회·추정0.125989달러·미정산0·자동재시도0이었다. 모두 정상 JSON이었고 v3는 출처 질문에서 내부 ID를 숨겼다. 그러나 신고 응답1은 접수 경로만 안내해 필수 입력 항목을 대폭 누락했고 응답2도 목격자·연락 방식이 빠졌다. v1도 두 번째 응답에서 목격자를 누락했다. 인과관계나 일반 품질 순위를 주장하지 않는다.

기존 출처 평가표가 질문에 없는 항목명까지 필수로 요구한 한계도 발견했다. 문서 제목만 표시한 v3는 ID 비노출 목적을 달성했지만 고정표의 부분 판정은 유지하고 과도한 기준일 수 있음을 별도 기록했다. 이 항목과 관계없이 신고 필수 정보 누락으로 초기 게이트는 실패했다.

## 결정과 검증

**v1 유지, v3 실험 후보 보존.** 초기 의미 게이트 실패로 확대 회귀·API/브라우저 확인·기본값 전환은 실행하지 않았다. JSON 실패가 없어 strict 후보의 실행 조건도 충족되지 않았다. v2의 과거 API 검증을 v3 근거로 재사용하지 않는다. 공개 서버 배포·재시작·실제 DB 변경은 하지 않았다.

생성257개·전체 Python586개와 Ruff 검사·형식 검사를 통과했다. 전체 테스트에는 초기화된 빈 임시 DB를 지정해 기존 legacy 테스트의 DB 의존성을 충족했다. 원응답과 원장은 tmp/answer-grounding-v3, 공개 발췌·판정·해시는 [보고서](../../generation_evaluation/reports/2026-10-15-answer-grounding-v3/README.md)에 보존한다.

사용자가 방향·범위를 정했고 AI가 구현·실행·비블라인드 의미 검토·문서화·게시를 담당했다. 독립 평가자·사람 품질 승인·사용자의 독립 숙련도 검증이 아니다. 다음에 검토할 수 있는 필수 근거 추출·답변 누락 확인 흐름은 제안일 뿐 채택하거나 구현하지 않았다.
