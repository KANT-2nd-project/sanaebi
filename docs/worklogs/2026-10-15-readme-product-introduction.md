## 문제와 결정

기준 커밋은 `cd16b9e`다. 앞선 문서 구조 정리 이후 루트가 서비스 소개보다 서버 확인·내부 운영 설명에 집중한다는 사용자 피드백을 받았다. 사용자는 소개 중심 개편, 규약 강화, 검수 지적 반영과 게시·Notion·새 일지 작성을 위임했다. UI 완료 전에는 화면 설명과 삽입 위치만 마련하고 촬영·모델 호출은 제외하기로 했다.

## 탐색 경로와 검증

- 첫 방문자: 루트 소개·사용 모습·현재 구성 → 빠른 시작 → 웹 상세 절차 → 서버 준비.
- 서버 학습자: 루트 → 서버 입문 → 의존성·서비스 → 추론 계산.
- 모델 교체 담당자: 서버 준비 → 추론 저장본·교체 → 서버 설정 규약·독립 확인.

- 문서 관리자: 루트 → 문서 색인 → 관리 가이드 → Notion 대응표.

명령은 package.json·설정·라우터·추론기와 정적으로 대조했다. 이번 작업에서는 모델·HTTP 질문·LLM·학습·test 평가·전체 Python 테스트를 실행하지 않는다. 문서 10개의 상대 링크·앵커 156개와 현재 문서에서 루트로 들어오는 링크 6개를 확인했다. 다섯 독자 경로에서 준비·설명·근거·관리 기준에 도달함을 대조했다.
