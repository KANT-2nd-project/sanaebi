# 최종 Luna 생성 모듈의 서버 통합

## 목적과 적용 범위

기준 main `b21d4ef5455d9a164be7382a7dd4ff326ed6df80`에서 `feat/server-generation-integration-20261015`를 만들었다. 독립 생성·평가에만 연결돼 있던 사용자 채택 구성을 서버에도 연결한다. 사용자 결정에 따라 `/assistant` 입력은 유지하고 출력은 `/ask`와 같은 `{ok,text,reason}`로 통일한다.

채택 프롬프트 원문은 수정하지 않았다. GPT-6 Luna / examples_answer_scope_v1 / single / xhigh / 4096토큰 / timeout180초 / prompt_json을 유지한다. temperature·자동 재시도·fallback·추가 튜닝은 없다. 상세 계약은 [서버 규약](../server-conventions.md), 프롬프트 채택과 알려진 한계는 [최종 프롬프트 기준](../generation-final-prompt.md)에 둔다.

## 구현과 변경 계기

- `load_runtime_settings`는 모델·프로필만 읽고 CLI의 `load_preset`이 JSONL 경로를 추가한다. 서버는 평가 모듈이나 평가용 파일을 읽지 않는다.
- 원본 knowledge_id·개정·제목·본문·순서를 공통 렌더러로 보존한다. 질문 서비스가 확보한 snapshot을 어댑터까지 전달하고 읽기 트랜잭션 종료 후 생성한다.
- 앱별 `GenerationAnswerer`는 첫 유효 검색 요청에서 클라이언트를 생성·재사용하고 종료 시 동기·비동기 클라이언트를 닫는다. 초기화만 잠그므로 원격 호출을 직렬화하지 않는다.
- 두 API는 공통 라벨 정책을 사용한다. 비검색·빈 문서·앞 단계 실패는 생성하지 않는다. `/assistant`는 재분류하지 않는다. 정상 생성만 문자열로 반환하고 생성 실패502·분류/문서 장애503·예상 밖 코드 오류500을 구분한다.
- `SANAEBI_ANSWER_PROVIDER`는 미설정/openai만 허용한다. 기존 실행기·평가는 비활성 레거시 재현용으로 보존한다.
- 모델180초·Next/nginx210초·웹240초를 연결했다. 전체 요청 시간 보장은 아니다. 웹503 안내·수동 재시도·입력 보존·취소·늦은 응답 무시를 유지한다. 개발 reload에 generation을 추가했다.
- trace는 모델 종료와 최종 생성 판정을 구분한다. 안전한 설정·snapshot 지문·역할별 프롬프트 해시(`prompt_roles_sha256`)·시간·사용량을 추가한다. 기존 콜백의 문자열 연결 `prompt_sha256`과 구별한다. 새 요약은 원문·키·예외 메시지를 넣지 않는다. 기존 opt-in trace는 요청·응답·콜백 원문을 포함할 수 있다.

독립 AI 리뷰에서 기록 실패가 정상 응답을 바꿀 가능성, 해시 이름 혼동, 실제 설정 기록 누락을 발견해 보완했다. 두 trace 기록 함수는 실패해도 요청 결과를 유지하고 예외 원문 없는 경고만 남긴다. 수정 후 독립 재검토와 회귀 검사를 통과했다.

브라우저의 첫8초 지연 시도는 관찰 시점 전에 응답이 완료되어 취소 증거로 사용하지 않았다. 소스 검토에서 확인창 동안 응답이 도착하고 unmount 전에 초안이 지워질 가능성을 확인하여, 승인한 동일 탭 이동에서 즉시 dispose하도록 보완했다. 확인 거부·새 탭 이동은 현재 요청을 유지한다. 해당 경합의 결정적 단위 검사는 변경 전 실패·변경 후 통과했고 별도 AI 리뷰도 통과했다. 실브라우저는60초 지연으로 다시 확인해 통과했다.

## 검증 자료

실행 원자료는 로컬 `tmp/server-generation-integration-2026-10-15/`에 보존한다. 실제 DB·환경 파일·대용량 원프롬프트는 게시하지 않는다. 저장된 계획·검증표를 기준으로 단위/HTTP mock, 분류기 회귀, 프록시, 브라우저, 제한된 실모델 호출을 나누어 확인한다.

최초 RED는 `/assistant`의 예전 provider별 비교 응답과 새 공개 계약의 불일치였다. 첫 전체 검사에서 과거 `adapter.execute` 패치와 두-provider HTTP 기대가 남아 실패했다. 활성 경로 테스트를 실제 generation + fake managed client로 옮기고, 레거시 체인 검증은 별도 오프라인 단위 검사로 보존했다. 그때 환경에 API 키가 없어 실제 생성 호출은 발생하지 않았다.

## 기여와 게시

사용자는 모델·프롬프트 채택, API 통일, 구현·검증·게시 범위를 결정했다. AI가 구현·테스트·실행·독립 AI 리뷰·문서화를 수행했다. 사용자의 독립 구현 숙련도나 사람 품질 승인으로 기록하지 않는다.

기능 브랜치에만 게시하며 main 병합·공개 서버 배포·실제 DB 초기화·예약 활성화는 수행하지 않는다. 기존 사용자 프로세스와 데이터·실험 이력을 보존한다.

작업 중 원격 main은 별도 임베딩 실험 기록 게시로 `a536ea14d203ccb1415ad096bdf04c58fb6ff5ac`까지 진행했다. 해당79파일은 조회·대조만 했고 이 기능 브랜치로 복제하거나 main을 덮어쓰지 않았다. 기준 main b21d4ef에서 생성한 기능 브랜치의 변경만 게시하며 이후 통합 시 문서3곳의 변경을 함께 보존해야 한다.
