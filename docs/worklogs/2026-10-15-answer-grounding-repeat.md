# v1·v3 반복 비교 일지

사용자가 이전 각2회 결과가 오차범위일 가능성을 지적하고 여러 번 시행하도록 요청했다. 이전 게이트 실패는 관측된 누락에 따른 보수적 채택 보류였으며, v3가 v1보다 나쁘다는 통계적 증거가 아니었다. 이를 분리해 확인한다. bug-triage와 project-doc-sync를 적용했다.

원격 main e577ba9와 일치한 격리 worktree에서 experiment/grounding-repeat-20261015를 만들었다. 원래 작업 공간의 분류기·프런트 변경과 실제 DB를 보존했다. 프로필·모델·추론 설정·API·기본값은 변경하지 않았다.

신고 문항 각40회, 출처 문항 각5회로 총90회를 사전 고정했다. 반복별 프로필 순서를 난수로 섞어 순차 실행하고 자동 재시도·품질 조기 중단은 하지 않는다. 별도 원장에 추정5달러 상한을 적용했다. 실행 전 프로토콜·코드·문서·프롬프트 입력 해시를 저장했다. 이전 표본은 합산하지 않는다.

기존 보호/연락 동시 필수 기준의 과도함을 발견해 초기5개 응답 열람 후 민감도 분석을 추가했다. 사전 기준의 주 분석은 그대로 유지하고, 완화 분석은 사후 추가라고 명시한다. AI가 전체 응답을 근거와 대조해 필드별 누락과 이유를 기록한다. 블라인드·사람 승인·독립 심사로 표현하지 않는다.

결과 기준 위치는 [반복 보고서](../../generation_evaluation/reports/2026-10-15-answer-grounding-repeat/README.md), 실행 절차는 [실험 안내](../../generation_evaluation/experiments/answer-grounding-repeat-20261015/README.md)다. 원응답·원장은 tmp/answer-grounding-repeat/runs에 보존한다. 공개 자료는 저장소의 합성 문서에서 생성된 응답만 포함한다.

사용자는 의문 제기·검증 범위를 정했고 AI는 실험 설계·실행·의미 판정·통계·문서와 게시를 담당했다. 동일 질문을 반복한 결과이므로 질문 전체의 일반 품질, 배포 실패 원사례의 안정성, 장기 서비스 안정성을 증명하지 않는다. 공개 배포·서버 재시작은 범위에 없다.

## 실제 중단·결과

사용자가 충분한 반복 후 중단·보고하도록 변경했다. 중단 시51개 응답이 저장됐고 다음 v1호출1개는 SIGINT로 취소됐다. 미확인 비용 예약은 유지했으며 재시도하지 않았다. 양쪽 모두 완료된1–25회 비교에서 완전 응답은 v1 15/25·v3 20/25, 완화 기준17/25·22/25였다. 추가 v3응답1개는 두 기준 모두 불완전하고 취소된 v1은 미판정으로 보존했다. 고정 표본의 확증적 검정으로 해석하지 않는다. 기존2회 결과로 v3 악화를 단정할 수 없다는 해석으로 보완하며 기본값은 변경하지 않는다.

프로필4개 테스트, Fisher 계산1,726개 표의 SciPy 대조, Wilson 끝점·대칭, 기록51개 일대일 대응을 확인했다. 프로덕션 코드를 수정하지 않아 전체 Python 테스트를 다시 실행하지 않았다. 원래 계획의 출처10회와 확대 검증은 중단 요청에 따라 실행하지 않았다.

## 게시·재조회 확인

실험6ffbcc1·결과1416a4c를 전용 브랜치에 게시하고, 원격 main에 추가 변경이 없음을 확인한 뒤 c60faf721cd9fafe051b244b556e2a0167ce9977로 병합·푸시했다. 통합 후 프로필4개 테스트를 다시 통과했다. 전체 Ruff 검사·형식313파일과 상대 파일 링크86개, 고정 입력 해시11개를 확인했다.

Notion [프로젝트 문서 안내](https://www.notion.so/3f805a3cdadc81e1a70bfe82c89cebe7), [서비스 처리 기준](https://www.notion.so/3f805a3cdadc81d7b909fc71ed78381b), [생성 개인 일지](https://www.notion.so/3f905a3cdadc8146a9bbedb690ab5ecf)에 ‘v1·v3 반복 비교 — 소표본 해석 보완’ 구역을 추가했다. 쓰기 직전 재조회하고 기존 분류 책임 계획 등 다른 작성자의 기록·속성을 보존했다. 저장 후 각 구역 전체와 고정 Git 링크2개씩 총6개를 재조회해 수치·중단·한계·기본값 유지가 일치함을 확인했다. 이 확인 기록을 후속 커밋으로 main에 게시한다.

사용자 요청에 따른 반복·중단·분석·기록·게시를 완료했다. 출처 반복·다른 질문 확대·서비스 기본값 승격은 이번에 실행하지 않았다. 모델 호출은 중단 뒤 추가하지 않았다.
