# 독립 생성 CLI와 실행 기록 저장·복원

## 범위와 결정

이전 게시 기준은 `85bb3ab`이다. 생성·평가 학습에서 작성한 변경만 기능별 로컬 커밋으로 정리했다. 분류 재구성, 루트 README, pyproject.toml 등 다른 작업의 변경은 포함하지 않았다. 원격 main을 fetch했을 때 시작 HEAD와 같았다. 이번 요청은 커밋까지로 처리했으며 push하지 않았다.

사용자가 `tmp/langchain-generation-review-2026-10-14`를 설계 근거로 지정했다. 얇은 LangChain 어댑터를 유지하고 독립 생성 경로와 평가를 먼저 검증한 뒤 서버를 연결한다. 보조 계약을 모두 선행 구현하는 대신 실제 실행 경로에 연결하며 필요한 검증을 추가한다. 구조화 출력·인용·입력 예산·snapshot 식별은 아직 목표이며 구현 완료로 간주하지 않는다. 초기 조사 자료는 로컬 tmp에 보존하고 커밋하지 않았다.

사용자가 공통 생성 진입점과 평가 호출 변경 등을 작성했다. 요청에 따라 AI가 계약 검증·복원 함수, 문서 로더·CLI와 테스트를 구현했다. 독립 테스트 담당은 새 로더·CLI 테스트만 작성했고 최종 통합·커밋·문서·Notion 갱신은 주 담당이 수행했다. 테스트 통과는 사용자의 독립 숙련도나 실제 모델 품질 증거가 아니다.

## 동작과 한계

- 문서 로더는 명시적 JSONL의 ID·개정·제목·본문과 순서를 보존한다. 잘못된 행·빈 파일·중복 ID는 모델 생성 전에 거부한다. 서버·DB를 import하지 않는다.
- CLI와 새 평가는 공통 생성 진입점을 사용한다. 평가는 프롬프트 구성부터 모델 호출·파싱까지 측정한다. 문서 읽기와 클라이언트 초기화는 제외하며 이전의 호출·파싱 시간과 구분한다.
- CLI는 상태·답변·원문을 출력한다. COMPLETED는 0, 처리된 생성 실패는 1로 종료하며 기타 오류는 전파한다. 기록 저장을 자동으로 연결하지 않았다.
- JSONL 저장은 직렬화 완료 후 배타적 파일 생성으로 덮어쓰기를 막는다. 쓰기 도중 장애의 원자적 복구는 미구현이다.
- 저장 형식의 schema_version·측정 범위·문서/프롬프트 fingerprint, 입력 예산·출력 예약량, 구조화 출력·인용 검증은 후속이다. 문서 문자열의 메타데이터 표시만으로 snapshot manifest 검증이 되는 것은 아니다.
- 실제 모델 호출·품질 평가·서버 연결·기존 코드 아카이브 이동·설치 패키지 포함은 미수행이다. 소스 checkout 루트에서 CLI help를 검증했다.

## 검증

- 생성 관련 unittest 108개 통과. 실제 파일 로더와 생성 경로를 사용하되 모델 클라이언트만 대체했다.
- 전체 unittest 최종 실행: 400개 실행, OK, 1개 skipped. 먼저 실행한 검사는 테스트 작성 중인 파일을 읽어 오류가 있었고, 작성 완료 후 전체를 재실행해 통과했다.
- 해당 생성·평가·테스트 Ruff check 통과. 전체 Ruff format --check는 182개 파일 통과.
- 전체 Ruff check는 무관한 `classification/tfidf.py`의 RUF059/F841 2건으로 실패했다. 다른 작업의 코드를 고치거나 커밋에 포함하지 않았다.
- `uv run --locked python -m generation --help` 통과. 실모델 호출·유료 API·다운로드·실제 DB 변경은 수행하지 않았다.
