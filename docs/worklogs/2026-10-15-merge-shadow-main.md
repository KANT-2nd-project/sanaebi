# shadow 기본 경로 main 통합

## 요청과 통합 기준

사용자가 shadow 채택 이후 main 병합을 요청했다. 최신 main cb38816과 기능 브랜치17de682를 별도 통합 작업 공간에서 병합한다. 원래 사용자 작업 공간의 웹 변경, 실제 DB, 실행 중 서버는 보존한다.

통합 기본값은 shadow / GPT-6 Luna / examples_answer_scope_v3 / single / xhigh / 출력16384 / timeout180초 / prompt_json이며 temperature·자동 재시도·fallback은 추가하지 않는다. gate는 환경변수로 명시하는 원복 경로다.

## 충돌 해소와 보존

문서6개 충돌은 최신 main의 v3 채택·S4/S5/S6 코드 정리 설명을 보존하고 shadow 실험·채택 기록을 합쳤다. 기존 v3 프롬프트 본문·프로필 구현·프리셋과 pyproject.toml·uv.lock은 main과 바이트 단위 동일함을 확인했다. 공통 모델 설정의 출력 한도만 승인된16384를 반영한다.

신규 테스트4개는 main의 책임별 폴더(runtime/evaluation)로 옮기고 루트 경로를 조정했다. gate 전제 회귀는 명시적 gate를 유지하고 현재 기본값 검사에는 v3를 사용한다. 과거 v1 출력 예산 실험의 mock fixture는 v1을 명시한다. 현재 v3로 과거 v1 후속 실험을 실행하면 호출 전에 거부하는 검사도 추가한다.

기존40문항·루브릭·보고서·원응답·판정은 기능 브랜치와 바이트 단위 동일하다. 과거 실행기는 기록된 고정 커밋에서 재현한다. 원래 v1/4096 실험 점수를 v3/16384 통합 품질 점수로 해석하지 않는다. 이번 통합에 유료 생성 호출은 추가하지 않는다.
