# 검색 인자 실험 최종 상태

실험 실행과 로컬 검증을 완료했다. 운영 채택은 보류하고 기존 설정을 유지한다. 공개 API·서버 기본값·모델·원본 데이터는 변경하지 않았다. 아래 완료는 사람 검수나 운영 승격을 뜻하지 않는다.

| 단계 | 상태 | 근거·한계 |
|---|---|---|
| 기존48 qrel v2 작성·독립 AI 검토·동결 | 완료 | `qrels-v2.json`, `qrel-author-notes.md`; v1 보존, 사후 과잉 필수 기준은 `qrel-errata.md` |
| 신규40 작성·독립 AI 검토·실행 전 동결 | 완료 | `new-confirmation.json`; SHA 불변, 반복 튜닝 없음 |
| 후보5/10/20/40/전체와 세 검색 정책 비교 | 완료 | `comparison-final.csv`, 압축 search 원자료, `claim-trace.json` |
| 1k/2k/4k 전달 형식 전체 예산 비교 | 완료 | Tiny 대체 토큰이며 Luna 실제 토큰과 구분 |
| 독립 관련도 판정·미판정 규칙 | 완료 | 1,920개 pool passage; P@5 공통48, nDCG 공통46; 두 질문은 IDCG0 |
| 조건부256/448 재분할 | 보류·미실행 | 잔여 근거의 제목·조치가 온전해 분할 손상 조건을 확인하지 못함; 순위·임계값 제외로 진단 |
| 개발 실제 답변·블라인드 판정 | 완료 | 288슬롯: API280+빈근거안내8, 재시도 포함292호출 |
| 신규40 실제 비교·블라인드 판정 | 완료 | 160슬롯,164호출;159 JSON 성공,1건 두 번 형식 실패로 정상 전달 미완료를 기록 |
| 최종 독립 결과 검토 | 완료 | P05 판정 오류1건 정정, 원판정·원집계 보존; 최종 `*-rechecked` 기준 |
| 실제 Tiny·격리 DB·모의 생성 API | 로컬 검증 완료 | 전체 삭제·기본 복원·현재 개정·미준비503/예약0 |
| 자정·mapping 복구·worker | 로컬 검증 완료 | 모델 파일 부재 상태의71/71 준비, 추론0; DB SHA/크기 보존, 회귀 테스트의 쓰기 경계·worker 복귀 |
| CPU2 cold/warm·동시1/2·메모리 | 개발 PC 측정 완료 | affinity2, cold는새프로세스/OS캐시유지; 실제 운영2vCPU 아님 |
| 전체 Python·Ruff·diff 검사 | 완료 | 최종 metadata 수정 후859 tests OK, Ruff check/format 통과; 신규 파일 별도 검사 |
| 사람 검수·실제2vCPU 운영·배포·활성화 | 미완료·범위 밖 | 운영 접속·설정 전환 없음 |
| 커밋·푸시·Notion | 제외 | 요청 범위대로 수행하지 않음 |

API 사용량과 원장456개를 대조했다. 실패를 포함한 모든 요청 비용은 정산 상태이며 추정 총비용 `$0.7265885`다. 기존 중단5호출 자료를 재실행하거나 이번 성공 수로 합치지 않았다.

최종 판정은 [보고서](README.md), 상세 검증은 [verification.md](verification.md), 원자료 위치는 [reproduction.md](reproduction.md)를 따른다. 원본 작업 폴더와 별도 작업 공간의 서버·data·artifacts 추적 변경은 없었고 데이터16파일 SHA가 일치했다. 원본 작업 폴더의 동시 갱신을 이번 실험에 통합하지 않았다.
