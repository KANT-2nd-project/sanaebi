# 원인 진단 보존본

이 폴더는 `tmp/retrieval-root-cause-2026-10-15`의 진단 원자료 사본이다. 기존 `manifest.json`의 15개 SHA-256은 모두 원본 바이트와 일치한다. 탐색용 Python 스크립트는 당시 로컬 경로를 포함하므로 실행 가능한 새 실험 코드로 오인하지 않도록 `.py.txt`로 보관했다. 원래 이름과 게시 이름의 대응은 `publication-map.json`에 있다. 원본 tmp 파일은 변경하지 않았다.

진단 당시 판단은 [보고서](report.md)에 보존한다. 후속 평가 기준과 공식 비교는 [상위 보고서](../README.md)를 따른다. 수동 질문 재표현과 정답 사실만 입력한 실험은 사후 원인 진단이며 일반 검색 품질 개선의 증거가 아니다.
