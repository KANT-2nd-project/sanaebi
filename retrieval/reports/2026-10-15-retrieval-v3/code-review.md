# 독립 코드 검토 기록

별도 읽기 전용 AI 검토자가 실험 실행기·동시성 측정·집계 코드를 검토했다. 사람 검수와 실제 운영 검증은 수행하지 않았다.

| 발견 | 수정과 확인 |
|---|---|
| 실험용 기존 선택 함수가 임시 전역 예산 값을 바꾸므로, 동시 두 요청에서 서로 다른 제한이 섞일 수 있음 | 가짜 동시 실행으로 무제한 요청이 5개/2,000자/8,000자로 바뀌는 경합을 재현. 벤치마크 선택 전체를 잠금으로 보호하고 대기는 전체 응답 시간에 포함. 이벤트 기반 두 스레드 회귀 테스트 통과 |
| 빈 결과가 한 구성에만 있으면 모든 구성의 공통 비교 문항에서 빠질 수 있음 | 개발 실행 전에 사전 절차를 명시. 공통 비교 집합은 판정 풀 완전성만으로 고정. raw 빈 precision은 null, 선정용 직접 관련도 점수는 0. 답변 정확도 점수와 구분. 실패 재현 테스트 후 수정·재검토 |
| claim 유무를 answerable 개수로 표시해 partial과 혼동 가능 | answerable·partial·필수 근거 문항 수와 빈 결과를 명시적으로 구분 |
| qrel/packet case ID 중복이 조용히 덮어써질 수 있음 | 중복과 서로 다른 case 집합을 오류 처리 |
| 완전히 채점된 빈 순위의 nDCG가 미판정과 같게 null로 표시됨 | ideal gain이 있으면 0, 관련 정답이 전혀 없으면 null. 빈 raw precision과 별도로 검증 |

실행기 검토는 인접 청크의 문서·개정·상위 절 경계, BGE 상위40 후보의 개별 임계값 미적용, CPU FP32·로컬 전용·입력 초과 오류, 점수 종류 분리, 전체 선택/상위40 검수 풀, DB 복제와 원본 보존, 동시성별 별도 프로세스 RSS를 포함했다. 수정 후 독립 검토자가 집중 테스트 17개 통과를 재확인했다. 실제 성능과 서버 결과 동등성은 별도 실행 기록으로 확인한다.

모든 변경이 끝난 뒤 전체 테스트·정적 검사와 결과 검토를 추가로 수행한다. 이 기록 자체가 전체 완료나 운영 승인을 의미하지 않는다.

## 후속 집계·성능 경계 검토

- 정해진 48요청의 미실행 지연을 0으로 놓아 계산한 p95 하한도 3초를 넘으면, 남은 요청이 어떤 값이어도 통과할 수 없다. BGE는 이 조건에서 조기 탈락시켰다. 부분 표본의 관측 p95를 전체 완료 p95로 기록하지 않으며 부분 실행으로 통과시키지 않는다. 별도 검토와 경계 테스트를 확인했다.
- 반환 근거 사이 중복은 문서별 원문 위치의 합집합과 총 길이 차로 계산한다. 동일 문자열 출현을 원문 중복으로 오인하지 않는다.
- 최종 독립 검토에서 집계기의 동결 qrel·packet 연결 검증 누락을 발견했다. CLI가 원본 SHA를 대조하고 같은 ID라도 다른 바이트면 거부하도록 수정했다. 불일치 회귀 테스트를 추가했다.
- 품질·전달량 동률에서 지연 미측정값으로 단순성을 먼저 비교할 수 있는 문제를 발견했다. 집계 출력은 지연 미반영 예비 순위임을 명시하며 최종 선정의 `require_latency=True`는 필요한 지연이 없으면 거부한다. 실제 측정값으로 순서가 바뀌는 테스트를 추가했다.
- 위 두 집계 보완은 별도 읽기 전용 검토자가 관련 테스트 9개 통과와 함께 재확인했다.

최종 확인 결정은 별도 함수로 고정했다. 평균 지표가 나아져도 C 성공 문항 하나를 잃으면 C 유지이며, 미판정 상태에서는 최종 결정을 거부한다. 실패하는 집중 테스트 후 구현했고 전체 회귀911개를 통과했다.
