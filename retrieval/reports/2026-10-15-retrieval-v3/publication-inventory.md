# 게시 범위 확인

이번 작업은 원격 main `c7f428a972e50f3d4ff95784d26583db69888ad5`를 기준으로 별도 작업 공간에서 시작했다. 원래 작업 폴더와 기존 실험 작업 공간의 자료를 수정하거나 이동하지 않는다.

| 자료 | 시작 시 확인 상태 | 이번 처리 |
|---|---|---|
| 이전 검색 인자·문맥 제한·실제 답변 비교 | PR #11과 후속 기록 커밋으로 이미 main에 게시됨 | 기존 원자료·응답·비용·v2 점수를 보존하고 후속 정정 링크 추가 |
| C 정책 및 신규 릴리스의 rag 기본값 | 이미 main 구현·기존 Notion 기록에 반영됨 | 이번 비교의 선정 판단과 분리. 불필요한 재구현이나 동일 기능의 중복 커밋을 만들지 않음 |
| 검색 원인 진단 tmp 자료 | 로컬 진단 원본 | [진단 보존본](diagnosis/README.md)에 바이트 보존 사본과 원본 이름 대응표 추가 |
| qrel v3·신규 확인40 | 이번 작성 | 독립 원문 검토·수정·동결 기록과 함께 추가 |
| 인접 확장·BGE 비교, 관련도 검수, CPU 측정 | 이번 실행 | 재현 코드·원자료·판정·요약과 한계 기록 |

`tmp/` 전체, 모델 가중치, SQLite, 가상환경, 환경 파일, 인증 정보는 커밋하지 않는다. 기존 모델·문서 DB·벡터는 새로 덮어쓰지 않으며 검색 실험은 색인 복사본을 사용한다. 실제 운영 접속·배포·유료 답변 API 호출은 이번 범위가 아니다.
