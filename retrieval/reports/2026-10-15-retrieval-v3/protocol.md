# 사전 고정 비교 절차

개발 결과 실행 전 작성. 사람 검수·운영 성능 승인이 아닌 AI 작성·독립 검토 기반 로컬 검색 실험이다. 이번 비교는 유료 API·생성 응답·자동 질문 재작성·운영 배포를 포함하지 않는다.

## 자료와 정책

- 기존 71문서 snapshot·298청크·Tiny revision과 360/60 분할·벡터 유지. qrel v2는 보존하고 개발 48개 v3와 별도 신규 40(답변가능30/부분5/불가5)을 독립 검토 후 동결한다. 신규 40은 개발 중 읽거나 튜닝하지 않는다.
- 기준선은 기존10후보/5근거/8000·2000자, A/B/C는 기존 실험 제한과 동일하다.
- 인접 확장: vector top5/8/12 각각에 같은 문서·개정·상위 절의 바로 앞뒤 최대1개 추가. 공통 상위 절 없으면 확장하지 않는다.
- rerank: vector top40 → BAAI/bge-reranker-v2-m3 raw score → top5/8/12. BGE revision953dc6f6f85a1b2dbfca4c34a2796e7dde08d41e, local CPU FP32, 자동 절단 없음. 후보에는 개별.35필터를 적용하지 않는다.
- 두 신규계열은 최고 cosine<.35일 때만 빈 결과. 추가 문자/토큰 제한 없음. 동일 원문 구간 중복병합, 점수와 순위는 구분한다. rerank점수는 관련 확률이나 cosine이 아니다.

## 지표·판정

필수 사실 간 AND, 대체 근거 간 OR, 대체근거 안 여러span은 AND. 모든span은 정확한 원문 위치를 검증한다. v3변경은 대체근거/필수성의 원문 검토로 결정하며 특정후보 성공을 기준으로 수정하지 않는다.

관련도0=무관,1=주제/절차관련,2=질문에 직접 부분근거,3=직접 핵심근거. 사실을 보되 설정·점수·순위·승패를 가린 독립AI가 판정한다. 기존 qrel-conditioned 판정도 재검토한다. 직접 관련도 precision은2이상이다. 판정합집합에 미판정이 남으면 해당질문 지표null. nDCG의 ideal은 모든 구성의 공통 검수풀에서 고정한다. 답변불가의 절차 안내는 자동오답으로 보지 않는다. 빈 결과의 raw precision은 null로 표시한다. 다만 후보 선정용 macro 직접 관련도 점수에서는 완전히 판정된 빈 결과를 0으로 계산하고, 공통 비교 문항은 판정 풀 완전성만으로 고정한다. 특정 구성의 빈 결과 때문에 비교 문항을 제외하지 않는다. 이는 답변 불가 안내의 정오 판정이 아니며 답변 가능 빈 결과 수도 별도 표시한다.

개발 선정: C 성공집합을 잃는 구성 제외. 남은 구성을 완전포함 수→공통유효문항 macro precision→평균전달문자 적음→warm p95낮음→단순성 순으로 정렬한다. 모든구성의 precision이 확정되기 전 최종선정하지 않는다. 완전동률이면 추가모델/확장 없는 구성, 이어 고정이름 사전순으로 결정한다.

CPUaffinity2에서 warm질문1·2동시 요청의 end-to-end검색p95(대기 포함) 모두≤3초, 검색프로세스 최대RSS≤6GiB를 채택조건으로 둔다. coldload는별도. timed path는질문벡터/재정렬 점수캐시 없이 실행하며모델만 재사용한다. 실제운영2vCPU가 아닌개발환경 측정이다.

개발 선정 후 후보 하나와 C를 신규 40에서한 번 비교한다. C 성공 문항 손실 또는macro precision악화 시 보류하고 C 유지. 결과 보고 후 동일 세트로 반복 튜닝하지 않는다. C보다 나은 구성 없음도 정상 결론이다.
