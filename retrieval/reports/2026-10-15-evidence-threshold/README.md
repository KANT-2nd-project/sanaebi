# 근거 개수·유사도 임계값 탐색 — 2026-10-15

## 목적·범위

최대5개가 최적인지, 점수 이상을 모두 선택하는 방식이 유효한지 실제 KoEn-E5-Tiny CPU 검색으로 비교했다. 서버 기본값·원본·벡터는 변경하지 않았고 LLM 호출·운영 전환·커밋·푸시는 수행하지 않았다.

기존 동결 회귀18+개발20과 답변불가10을 사용했다. 이미 공개된 AI 작성·검토 개발 자료이며 사람 검수·독립 최종 평가가 아니다. holdout20은 사용하지 않았다. 처음25설정에서0.5 이상 하한의 누락을 확인한 후0.3/0.35/0.4/0.45/0.475를 추가해 총40설정을 탐색했다. 추가 탐색 사실을 보존하며 이 결과만으로 일반 성능을 주장하지 않는다.

기준 코드2dbe3f7, 문서71·청크298, Tiny 고정revision292c09c78c71a3f00ed56ee0d1ed9f0d39182fc9. 기존 준비DB·색인 복사본에서 현재개정 벡터를 읽었다. 전체 원문과 qrel SHA·원문 span·snapshot을 대조했다. 기존 본문360토큰/중첩60, 근거당2000자·총8000자 유지. 정규화벡터 내적 점수로 필터하고 기존 병합·예산 코드를 그대로 사용했다.

## 주요 결과

완전포함은 질문에 지정된 모든 필수 원문 구간이 최종 근거에 포함됐다는 뜻이다. LLM 정답률이 아니다. 답변불가의 '빈 결과'는 근거가 선택되지 않았다는 뜻이며 정답 거절 성공을 뜻하지 않는다. 관련 절차를 제공할 수 있는 답변불가 질문도 있다.

'개수제한 사실상 없음'은298개 상한이며 현재 청크 수와 같다. 문자 예산은 유지하므로 임계값 이상이 전부 최종 전달되는 무제한 방식은 아니다. 0.35에서는 평균21.53개 근거를 전달했다.

5→8의 추가 성공은 D07(구매 승인과 계정권한 자동발급 구분)이다. 기존 성공34개는 유지했다. 0.35·개수상한298은 R08·R14까지 회복했다. 그러나 평균 전달량은 기존 대비 약4.25배이며 지정 정답 문서 외의 문자가 평균6660자다. 이 수치는 불필요성의 대리 지표일 뿐 다른 문서가 모두 무관하다는 판정은 아니다.

답변가능 질문의 최고점은0.456~0.831, 답변불가는0.324~0.641로 겹쳤다. 단일 절대점수만으로 답변가능 여부를 분리하지 못한다. 0.475는 기존 완전포함34개를 유지해도 답변가능2개가 빈 결과가 됐다. 완전포함 집계만 보는 것은 충분하지 않다. CSV의 threshold0.47 이름은 표시 반올림이고 실제 threshold 열은0.475다.

## 판단

- 최대5개는 최적값으로 입증되지 않았다. 8개는 이번 개발세트에서 추가1문항을 회복했고10개는 더 늘려도 이득이 없었다.
- 균형 후보는 **0.40·최대8·8000자**다. 기존 성공 유지·개발20/20, 후보10·최대8보다 전달량 감소와 답변불가 빈 결과3개를 보였다. 실제 답변 품질 검증 없이 서버에 채택하지 않았다.
- 보수적 후보 **0.45·최대5**는 완전포함34개를 유지하면서 전달량을 줄였다. 누락 개선은 없다.
- 근거 누락 최소화 후보 **0.35·개수상한298·8000자**는37/38이나 많은 추가 문맥을 전달한다. 불필요한 문맥·비용·답변의 조건 혼동 여부를 후속 평가해야 한다.
- 점수 필터가 모든 질문의 답변가능 여부 판단을 대신하지 못한다. 신규 미열람 자료와 실제 생성 비교 전까지 현재 서버 설정을 유지한다.

## 검증과 재현

48질문에서 실험 기준선의 chunk ID·본문이 실제 RetrievalService.retrieve와 일치했다. 전체1920 결과의 상한·총문자·개별문자·임계값과 요약 집계를 검사했다. 기존 DB·색인의 SHA256 전후 일치. 임시 복사 색인만 사용했고 문서 임베딩 재생성·LLM 호출은0이다. 질문 임베딩은 설정 간 재사용했다. 시간값은 단회 개발PC 관측이며 기준선 추가대조가 섞인 assembly_ms는 후보속도 비교에 사용하지 않는다.

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
uv run --locked python -m retrieval.experiments.thresholds \
  --artifact-root tmp/answer-evaluation --model tmp/tiny-model \
  --output tmp/evidence-threshold-reproduction
```

준비된 artifact-root와 모델은 로컬 전제이며 다운로드 링크가 아니다. 초기 실행은 tmp/evidence-threshold, 확장 실행은 tmp/evidence-threshold-expanded에 원결과를 보존했다. 이 작업 공간의 tmp 아래 results.json에1920건의 실제 선택span·점수가 있다.
