## 연결·복원 검증

격리된 SQLite에서 실제 Tiny로 검색했다. 기본 묶음 재사용 reset 후71개 문서 모두 새 revision에 연결됐다. reset 중 모델 로딩을 실패하도록 막아도 성공했다. 실제 Tiny·모의 생성기 HTTP 요청은200, 모의 호출1회, 실제 LLM 호출0회였다.

로컬 CPU affinity를 코어2개로 제한했다. 이는2vCPU 운영 서버 실측이 아니다. 최초 묶음 생성은 약45.1초였다. 재실행의 검증·재사용 시간은 생성 시간으로 비교하지 않는다. 마지막18문항에는 lazy 첫 로딩도 포함되므로 p95를 안정 상태 지연으로 해석하지 않는다.

답변 불가능4문항도 검색만 실행했다. 유사도 후보가 있다는 사실을 거절 성공이나 사실성 검증으로 판단하지 않았다.

## 후속과 원자료

**full 유지**가 현재 결정이다. 새 분할에서 빠진 정책 조건·문맥을 보완하고, 별도 사람 검수 질문과 실제 LLM 근거 충실도 평가 후 rag 전환을 판단한다. 실제2vCPU 동시 부하, Docker 배포·rollback, 운영 자정 실행은 별도 검증 대상이다.
