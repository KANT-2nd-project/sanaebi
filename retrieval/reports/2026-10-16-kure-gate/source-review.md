# 모델 실행 전 원문·의도 검수

2026-10-16. 작성 AI와 별도 읽기 전용 검토 AI 두 명이 원문과 기존 질문을 검토했다. 사람 검수가 아니며 모델 결과를 보고 정답을 바꾸지 않았다. 개발68·확인40의 원문 span은 Python 문자열 위치로 전수 대조했다. 기존 qrel v3 48문항의 질문·필수 근거는 변경하지 않았다.

## 검토 범위와 수정

- 기존 보고서 JSON을 재귀 탐색한 question/query 문자열155개(빈 문자열·자리표시자 포함)를 대조했다. 작성자의 초기128개, question만 검사한148개보다 범위를 넓혔다. 이는155개의 독립 정책 질문을 뜻하지 않는다. gzip·일반 텍스트의 모든 문장까지 전수 검색했다고 주장하지 않는다.
- 초기 검토에서 중첩 holdout 문항을 놓쳤고, 후속 검토에서 H12 선물 처리와 H22 반납 완료 대체안도 기존 질문 중복임을 발견했다. 이 대체안들은 폐기했다. 초안·폐기안·검색 출처는 `source-review-drafts.json.gz`로 보존했다.
- 최종 H12는 반복·분산 혜택을 한 관계로 신고하는 규칙(ieum-045[432:477]), H19는 비동기 검토 요청 항목(ieum-061[239:323]), H22는 자산 지연 시 임의 급여 공제 금지(ieum-023[626:670])로 교체하고 별도 검토자가 승인했다. H22는 실제 AST-620 처리 상태를 알 수 없어 부분 가능이다. 법적 적법성 전반을 판단하는 자료가 아니다.
- G05·H03·H04·H10·H21의 동등 근거를 보완했다. H21 대체 구간은 승인/보완 요청 기한만 필요한 최소 문장으로 좁혔다. H18은 질문에 필요한 항목을 명시했고, 따라서 표현 다양성 검증이라고 주장하지 않는다.
- H25의 잘못된 비교 문항 번호를 수정했다. H28은 현재 운영 드라이브의 승인본 버전·적용일을 묻도록 구별했다. 배포 원문의 version 필드로 실시간 운영 상태를 추측하지 않는다.
- 기존 U01·U02·U05는 무관, 나머지 U는 관련 정책이 있으나 실제 답이 없거나 조건부 안내만 가능하다고 판정했다. U03의 연락 경로는 Slack/포털 불가 조건을 보존한다. 기존48의 무관3개는 신규 무관10개 차단 목표의 분모에 넣지 않는다.
- 개발·확인의 신규 무관10개는 각각 회사 맥락5·일반 질문5로 구성했다. G14 스톡옵션, G19 동호회 지원, H34 셔틀, H36 검진 지정병원·예약은 원문에 관련 제도가 없다.

## 제한과 동결

정확한 질문 문자열 중복은0개다. 정책 문서 자체를 완전히 분리한 평가는 아니며 H03 등은 이전 문항과 같은 정책군의 다른 사실을 묻는다. AI 의도 검토가 의미 중복의 완전한 부재를 보장하지 않는다. 관련도 precision/nDCG 전수 정답은 새로 만들지 않았다.

두 검토자는 최종 교체안과 수정한 최소 구간을 승인했다. 문항은 모델 실행 전에 `freeze.json`의 SHA로 고정한다. 확인40은 개발 적격 후보가 있을 때 한 번만 사용하며, 개발 부적격이면 미사용으로 보존한다.
