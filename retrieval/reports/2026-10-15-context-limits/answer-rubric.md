# 빠른 비교의 사전 독립 AI 판정 기준

지정12문항·각 구성1회 개발 진단이다. 사람 검수나 새로운 확인 세트가 아니다. 질문·기존 qrel·회사 원문만 본 독립 검토자가 선정과 아래 기준을 승인했다. 결과·순위·설정 매핑·비용은 제공하지 않았다.

설정·점수·비용·매핑을 가린 모든 최초 응답과 재시도를 판정한다. 의미가 같으면 충족하며 원문 span의 모든 부가 정보를 새 필수 조건으로 요구하지 않는다. JSON 준수는 기존 파서 상태로 따로 집계한다. 비JSON도 본문은 판정하지만 정상 전달 성공으로 세지 않는다. 빈 근거 안내는 attempt0으로 판정한다.

판정 필드: `missing_claims`, `major_error`, `unsupported_assertion`, `abstention_correct`, `content_complete`, `reason`. required claim을 모두 전달하고 중대/근거없는 확정이 없으며 답변불가 질문의 한계를 올바르게 밝히면 내용 완전이다. 금액·기한·자격·예외를 잘못 확정하거나 금지 행위를 허용하거나 실제 개인 상태를 조회한 것처럼 답하면 major_error다.

판정자는 블라인드 패킷과 이 기준, 필요한 회사 원문만 읽는다. 원 판정에 오류가 발견되면 원파일을 보존하고 독립 재검토·정정 이유를 남긴다. 내용 오류를 이유로 LLM을 재호출하지 않는다.
