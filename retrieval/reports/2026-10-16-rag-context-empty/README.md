초기 판정은 근거 없는 요청 채택·문맥 보충 보류였다. 이후 사용자가 기존 대비 관측 개선을 우선하여 문맥 보충도 서버 기본값으로 채택했다. 이는 사전 기준 통과로 판정을 바꾼 것이 아니다. 각 조건 1회인 AI 평가이며 반복 안정성·일반적인 품질 향상·운영 신뢰성 검증은 아니다.

## 결정과 남은 문제

- **빈 근거 응답 채택:** 실제 검색 0건 두 질문이 정상 생성됐고 네 질문 모두 내용 기준을 충족했다. 도움 소개·지원금 질문은 근거가 있었으므로 빈 근거 실험으로 바꿔 보고하지 않는다. 정상 빈 게시 자료는 mock으로만 검증했다.
- **문맥 보충 보류:** 사고 질문의 중요한 근거는 복원됐지만 ieum-035의 채널 또는 포털과 ieum-058의 채널과 포털 표현 차이가 드러났다. 정책 우선순위를 모델이 만들어내도록 하지 않고 문서 소유자가 둘 다 필요한지 확인하는 것이 다음 조치다. 이번에 원문 정책은 수정하지 않았다. 기존 사고 답변의 형식 실패도 남은 한계다.
- 서버 RAG만 신규 프로필을 사용한다. full·독립 CLI와 기존 15개 프로필은 유지한다. 원복은 SANAEBI_RAG_PROMPT_PROFILE=examples_answer_scope_v5 지정 후 사용자 재시작이다.
- DB·색인 장애는 생성하지 않고 기존 오류를 유지한다. 빈 근거 생성도 예산·동시성·timeout·파싱 제한을 받는다. 명시적 gate 라벨 차단은 유지한다.
- 두 변경 결합은 채택하지 않았다. 신규 프로필의 업무 절차 전반에 대한 반복 검증·재시작 후 실서버 확인은 하지 않았다.
