# 점수만으로 근거 선택 — 2026-10-15

## 조건

사용자 요청에 따라 최대 근거 개수 제한을 제거했다. 점수 이상인 현재 유효 청크 전체를 검색 후보로 사용하고 원문 중복을 병합했다. (A) 총8000자·근거당2000자를 유지한 경우와 (B) 개수·총문자·개별문자 제한을 모두 제거한 순수점수 선택을 비교했다. 기준선은 기존 후보10·최대5개다. 점수0.25/0.30/0.35/0.375/0.40/0.425/0.45/0.475/0.50/0.55/0.60의 22설정+기준선, 총23설정을 실행 전에 정했다.

기존 공개 회귀18·개발20·답변불가10, 동일71문서·298청크·KoEn-E5-Tiny 고정revision과 이전 색인이다. holdout20은 사용하지 않았다. 개발 자료 재탐색이며 사람 검수·새 독립 평가가 아니다. 문서 임베딩·LLM 호출·서버 설정 변경·운영 배포·커밋·푸시는 하지 않았다.

## 판단

점수만 선택하는 방식은 가능하고, 낮은 하한에서 필수 근거 포함은 높아졌다. 그러나 선택량 변동이 커지고 답변불가 질문에도 많은 문맥을 제공했다. 이번 자료에서는 점수만으로 답변가능 여부나 필요한 문맥 양을 안정적으로 결정하지 못했다.

개수 제한 없이 진행한다면0.35+총8000자는 이번 개발 자료의 비교 후보로 의미가 있다. 무제한0.35와 동일37/38을 더 적은 문맥으로 달성했다. 기존0.40+최대8 후보보다 포함2개를 더 회복하지만 전달량은약2.8배다. 실제 생성의 정확도·조건 혼동·비용·지연은 별도 비교가 필요하며 현재 서버 설정은 변경하지 않았다.
