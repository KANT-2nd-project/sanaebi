# 과거 독립 평가 실행기

이 폴더와 `sanaebi_assistant.py`는 과거 실험·독립 실행 재현용으로 보존합니다. 현재 서버는 import하거나 호출하지 않습니다.

현재 생성은 [generation](../generation/README.md), 평가는 [generation_evaluation](../generation_evaluation/README.md), 서버 연결 계약은 [서버 규약](../docs/server-conventions.md)을 따릅니다. 과거 결과를 최종 Luna 구성의 실행 결과로 다시 분류하지 않습니다.
