# 과거 FastAPI 프로토타입

[fastapi_main_tmp.py](fastapi_main_tmp.py)는 초기 실험 코드를 원본 그대로 보존한 자료입니다. 현재 서비스 구현이나 실행 예제로 사용하지 않습니다. 보관 위치로 이동한 뒤의 실행과 모델·파일 상대 경로는 지원하지 않습니다.

현재 서버는 [app/fastapi_main.py](../../app/fastapi_main.py)이며, 실행 방법은 [프로젝트 README](../../README.md)를 따릅니다. 서비스 흐름은 [서비스 설계](../../docs/service-architecture.md), 현재 분류 기준은 [라벨 문서](../../docs/label-taxonomy.md)에 있습니다.

## 현재 구현과 다른 점

- 이 파일에는 독립적인 FastAPI 앱과 과거 직원·분류 API가 있습니다. 현재 서버는 이를 import하거나 라우트로 등록하지 않습니다.
- 질문 응답은 `answer` 필드를 사용합니다. 현재 서버의 `ok/text/reason` 계약과 다릅니다.
- 분류 라벨은 `it`, `hr`, `finance`, `general_affairs`, `other`입니다. 현재의 `SEARCH_KNOWLEDGE`, `CLARIFY`, `UNSUPPORTED`와 다른 실험입니다.
- 모듈 import 시 모델을 로드하는 코드와 async 라우트에서 동기 추론을 직접 실행하는 코드가 있습니다. 현재 서버의 모델 연결 구현으로 복사하지 않습니다.

## 재사용 전에 확인할 사항

직원 입력 모델에 비밀번호가 있고 출력 모델이 이를 상속하므로, 이 앱을 실행하면 응답에 민감 필드가 포함될 수 있습니다. 직원 파일의 읽기·쓰기에 인증 처리가 없고 ID 생성도 동시 등록을 원자적으로 처리하지 않습니다. 실제 직원 데이터나 인증 정보로 실행하지 않습니다.

직원 기능은 현재 서비스 목표에 맞는지 먼저 판단해야 합니다. 재사용이 필요하면 입력·출력 모델, 인증·권한, 비밀번호 취급과 저장 동시성을 별도로 설계해야 합니다. 이 보관 문서는 해당 문제를 수정하거나 안전한 운영을 보장한다는 의미가 아닙니다.
